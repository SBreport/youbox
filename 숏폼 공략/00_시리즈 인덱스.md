## TL;DR

숏폼(쇼츠·릴스·틱톡)을 활용해 잠재 고객을 모으고 매출로 전환하는 통합 전략 강의. **풀링 숏폼**(정보 전달로 트래픽·로열티 모음)과 **키 숏폼**(상품 판매)의 두 트랙을 **10:1 비율**로 운영하는 게 기본축. 제작 단계는 **주제 선정 → 템플릿 → 자료 조사 → 도입부·표시제목·썸네일·제목 → 원고 → 콘티 → 녹음 → 촬영 → 편집 → 업로드** 의 10단계로 정형화돼 있다. **0.5초 안에 주의 끌기**, **300자/30초 원고**, **10초당 1개 감정 포인트**(천만 뷰는 5~6초당 1개) 같은 정량 기준이 핵심. 강사가 **2022년 1월부터 매일 2시간**씩 한 **숏폼 끝내기**(잘된 영상 분해 → 강점 추출 → 내 영상 적용)는 7개월 만에 60만 팔로 달성의 원동력이며, **나만의 구조 사전**과 **나만의 템플릿**을 누적하는 게 장기적 차별화 포인트.

## 🎯 시리즈 관통 메시지 (5개)

1. **0.5초 안에 주의를 끌어야 한다** — 도입부 후킹은 1초도 길다. 정보 가치가 아무리 좋아도 도입부가 약하면 그 영상은 망한 거다.

2. **나만의 구조 사전과 나만의 템플릿을 누적해라** — 잘된 숏폼 분해 → 구조만 가져옴(주제는 카피 X) → 워드/노션/엑셀에 모음. 구조는 유통기한이 없다, 다다익선.

3. **양으로 승부, 피드백 루프로 빨리 늘어난다** — 왕초보가 고민한다고 퀄 안 오름. 미드폼 주1회 vs 숏폼 주5회 = 피드백 5배. 강사는 하루 12개도 만들어봄.

4. **풀링과 키의 비율을 고정하지 말고 측정하며 조절** — 기본 10:1, 매출·팔로 전환율(1~5%) 보면서 9:1, 8:1, 11:1 등으로 동적 운영. 키만 올리는 채널은 단기 매출 OK 장기 정체.

5. **숏폼 끝내기는 매일 하면 복리로 성장하는 행동** — 단기 성과는 안 보이지만 누적되면 양산형 숏폼과 차별화되는 고성과 능력. 처음 한 편 1시간 → 간소화 4가지로 10~20분 가능.

- [ ] 캡컷·VidIQ·뷰트랩 등 필요 도구 설치

### Phase 1. 끝내기 시작 (1~2주차)
- [ ] 숏폼 끝내기 첫 3개 진행 (간소화 4단계 버전, 10~20분/편)
- [ ] 도입부 구조 5개 사전에 모으기
- [ ] 문구 강화 5가지 직접 적용해보기

### Phase 2. 제작 시작 (2~4주차)
- [ ] 풀링 숏폼 주제 3개 선정 (뷰트랩 검증 필수)
- [ ] 4가지 템플릿 중 하나 선택 → 첫 풀링 숏폼 제작·업로드
- [ ] 첫 키 숏폼 1개 제작 (6가지 템플릿 중 내 상품에 맞는 것)
- [ ] 유튜브·인스타·틱톡(가능하면 쓰레드까지) 동시 업로드

### Phase 3. 운영 안정화 (1~3개월)
- [ ] 풀링:키 10:1 비율로 시작, 매출·팔로 전환율 측정
- [ ] 매주 숏폼 끝내기 최소 3개 누적
- [ ] 나만의 템플릿 1개 발굴
- [ ] 나만의 개성·말투·디테일 1개 정해서 영상마다 유지

### Phase 4. 차별화 (3~9개월)
- [ ] 카테고리 1~10등 채널 벤치마킹 정기 진행
- [ ] 외국 정보 활용 1회 이상 (탄냄비 사례처럼)
- [ ] A/B/C 강점 테스트 (3계정 또는 시기별)
- [ ] 풀링·키 비율 데이터 기반 조정 (9:1 → 8:1 또는 11:1)
