# 숏폼 공략 — 시리즈 인덱스

## 🎯 시리즈 한 줄 요약

숏폼(쇼츠·릴스·틱톡)으로 잠재 고객을 모아 매출로 전환하는 통합 전략 강의. 풀링(정보 전달·트래픽)과 키(상품 판매)의 두 트랙을 10:1 비율로 운영하되, 매일 잘된 영상을 분해하는 "숏폼 끝내기" 루틴이 모든 성장의 기반이다.

> [!IMPORTANT]
> **시리즈 관통 원칙: 양이 곧 실력이다.** 강사는 2022년 1월부터 매일 2시간 숏폼 끝내기를 지속해 7개월 만에 60만 팔로워를 달성했다. 고민할 시간에 1편을 더 만드는 것이 최단 성장 경로다.

---

## ⏱️ 시리즈 핵심 5가지

1. **0.5초 안에 주의를 끌어야 한다**
   도입부 후킹은 1초도 길다. 정보 가치가 아무리 좋아도 도입부가 약하면 그 영상은 노출 0이다. 숏폼 피드에서 시청자의 손가락은 이미 위로 올라가 있다.

2. **나만의 구조 사전과 나만의 템플릿을 누적해라**
   잘된 숏폼을 분해해 구조만 가져온다 (주제는 카피 금지). 워드·노션·엑셀에 쌓는다. 구조는 유통기한이 없고 다다익선이다.

3. **양으로 승부, 피드백 루프로 빨리 늘어난다**
   왕초보가 고민한다고 퀄리티가 올라가지 않는다. 미드폼 주 1회 vs 숏폼 주 5회는 피드백 5배 차이다. 강사는 하루 12개도 만들었다.

4. **풀링과 키의 비율을 고정하지 말고 측정하며 조절한다**
   기본 10:1. 매출·팔로워 전환율(1~5%)을 보면서 9:1, 8:1, 11:1로 동적 운영한다. 키만 올리는 채널은 단기 매출은 OK지만 장기 성장이 5만~10만에서 정체된다.

5. **숏폼 끝내기는 매일 하면 복리로 성장하는 행동이다**
   단기 성과는 안 보이지만 누적되면 양산형 숏폼과 차별화되는 고성과 능력이 만들어진다. 처음 한 편에 1시간 걸리던 끝내기가 간소화 4가지로 10~20분으로 줄어든다.

## 📚 시리즈 전체 흐름

이 시리즈는 4개의 파트로 구성된다.

**파트 1 — 제작 매뉴얼 (1~3강)**: 숏폼이 무엇이고 왜 해야 하는지부터 시작해, 원고 템플릿 4가지와 자료 조사 방법, 도입부·썸네일·원고·콘티·편집까지 영상 1편을 만드는 전 과정을 단계별로 다룬다. 3강이 이 파트의 핵심으로, 도입부 화면 8가지와 문구 강화 5가지 등 시리즈 전체를 관통하는 핵심 기술이 집중돼 있다.

**파트 2 — 학습 루틴 (4강)**: 제작 방법을 아는 것과 잘 만드는 것은 다르다. 잘된 영상을 해부해 성공 요소를 추출하고 내 것으로 재해석하는 "숏폼 끝내기" 루틴이 이 파트다. 강사가 60만 팔로워를 달성한 진짜 비결이다.

**파트 3 — 수익화 전략 (5강)**: 풀링으로 팬을 모았다면 어떻게 매출로 전환하는가. 키 숏폼 6종 템플릿, 풀링:키 비율 동적 조절법, 설득 꿀팁 4가지, 나만의 개성 구축법을 다룬다. 관여도 개념이 이 파트에서 처음 등장하며, 6강 FAQ와 연결된다.

**파트 4 — 실행 (6강)**: 이론을 행동으로 연결하는 실행강이다. 회원 육아 사례·33만 릴스 워크스루·370만 쇼츠 해체로 실제 제작 프로세스를 트레이싱하고, FAQ 10개로 실무 쟁점을 전부 커버한다. 강의가 끝나면 바로 영상 제작을 시작할 수 있도록 설계됐다.

## 📅 액션 로드맵 (Phase 0~4)

체크박스로 진행 상황 트래킹:

### Phase 0. 준비 (1주차)
이 단계의 목표: 도구와 사고방식을 갖추고, 지금 내 위치를 정확히 파악한다.
- [ ] 6개 강의 노트 정독 + 💭 내 메모 채워넣기
- [ ] 나만의 구조 사전 도구 결정 (워드/노션/엑셀 중 하나)
- [ ] 캡컷·VidIQ·뷰트랩 등 필요 도구 설치

### Phase 1. 끝내기 시작 (1~2주차)
이 단계의 목표: 분석 루틴을 시작하고 첫 구조 사전 자산을 만든다.
- [ ] 숏폼 끝내기 첫 3개 진행 (간소화 4가지 버전, 10~20분/편)
- [ ] 도입부 구조 5개 사전에 모으기
- [ ] 문구 강화 5가지 직접 적용해보기

### Phase 2. 제작 시작 (2~4주차)
이 단계의 목표: 첫 번째 숏폼을 실제로 만들어 업로드한다. 완성도보다 완료가 중요하다.
- [ ] 풀링 숏폼 주제 3개 선정 (뷰트랩 검증 필수)
- [ ] 4가지 풀링 템플릿 중 하나 선택 → 첫 풀링 숏폼 제작·업로드
- [ ] 첫 키 숏폼 1개 제작 (6가지 키 템플릿 중 내 상품에 맞는 것)
- [ ] 유튜브·인스타·틱톡(가능하면 쓰레드까지) 동시 업로드

### Phase 3. 운영 안정화 (1~3개월)
이 단계의 목표: 제작과 분석 루틴을 동시에 돌리면서 내 채널의 평균값을 탐색한다.
- [ ] 풀링:키 10:1 비율로 시작, 매출·팔로워 전환율 측정
- [ ] 매주 숏폼 끝내기 최소 3개 누적
- [ ] 나만의 템플릿 1개 발굴
- [ ] 나만의 개성·말투·디테일 1개 정해서 영상마다 유지

### Phase 4. 차별화 (3~9개월)
이 단계의 목표: 데이터 기반으로 운영을 최적화하고 양산형과의 격차를 만든다.
- [ ] 카테고리 1~10등 채널 벤치마킹 정기 진행
- [ ] 외국 정보 활용 1회 이상 (해외 미소개 주제 발굴)
- [ ] A/B/C 강점 테스트 (3계정 또는 시기별)
- [ ] 풀링:키 비율 데이터 기반 조정 (9:1 → 8:1 또는 11:1)
