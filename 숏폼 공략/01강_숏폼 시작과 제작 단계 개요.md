## TL;DR

숏폼은 수익화를 막 시작했거나 미드폼 제작 여력이 부족할 때 트래픽 확보 수단으로 유효하다. 핵심 장점은 원소스 멀티유즈·로열티 축적·빠른 실력 상승 세 가지다. 정보성 풀링형 숏폼은 도입–본문–결론 3파트로 구성되며, **도입부에서 0.5초 안에 주의를 끄는 것**이 전체 성패를 가른다. 제작은 주제 선정부터 시작하고, 뷰트랩에서 미드폼 주제 찾듯이 또는 쇼츠 필터로 주제를 고른다.

## 🎯 숏폼/미드폼 용어 정리

> **유형**: 개념
> **타임스탬프**: [00:34] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=34

### 한 줄 요약

이 강의에서 "숏폼"은 유튜브 쇼츠·인스타 릴스 등 짧은 영상 전체를, "미드폼"은 유튜브에 올리는 긴 영상을 가리킨다.

### 핵심 내용

- **숏폼**: 유튜브 쇼츠 + 인스타 릴스처럼 짧고 세로형인 영상 포맷을 통칭
- **미드폼**: 유튜브에 올리는 가로 긴 영상 (일반 유튜브 영상)
- 이 두 용어는 강의 전반에 걸쳐 고정 명칭으로 사용

### 강사 비유 / 예시

> "유튜브 쇼츠, 인스타 릴스처럼 새로운 형식으로 된 영상들을 제가 다 지칭해서 숏폼이라고 말을 하도록 하겠습니다."

온피디 님이 유튜브에 올리는 긴 영상 → 미드폼으로 부른다고 직접 예시를 든다.

### 주의 사항

- 외부에서는 숏폼/쇼트폼이라는 용어가 혼용되지만, 이 강의 시리즈 내에서는 **"숏폼"** 고정
- 음성인식 오타 주의: "효뽕", "쇼폰", "초폰" → 숏폼 / "위드폼", "위드폼" → 미드폼

## 🎯 숏폼 장점 ① 원소스 멀티유즈

> **유형**: 개념
> **타임스탬프**: [01:15] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=75

### 한 줄 요약

숏폼 하나를 여러 플랫폼에 동시 업로드해 단일 플랫폼 리스크를 줄이고 새로운 타겟층을 발굴한다.

### 핵심 내용

- 하나의 숏폼 → 유튜브 쇼츠, 인스타 릴스, 틱톡, 쓰레드, **네이버 클립** 동시 업로드 가능
- 효과 두 가지:
  - 단일 플랫폼 의존 리스크 감소
  - 플랫폼별 특성에 따른 신규 타겟층 발굴 → 수익 구조로 유입 가능

### 강사 비유 / 예시

> "유튜브가 망할 일이 없습니다만은 우리가 단일 플랫폼에 대한 리스크가 줄어듭니다."

네이버 클립은 강사가 별도로 강조한 플랫폼 — 네이버 검색 유입까지 잡을 수 있는 기회로 제시.

### 주의 사항

- 플랫폼마다 영상 규격·해시태그 전략이 다를 수 있으므로 단순 복붙이 아닌 플랫폼 최적화가 필요 (이 파트에서 강사가 상세히 다루지는 않음, 추후 강에서 다룰 가능성)

## 🎯 숏폼 장점 ② 로열티 쌓기

> **유형**: 개념
> **타임스탬프**: [01:48] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=108

### 한 줄 요약

미드폼 주 1회 vs 숏폼 주 3~7회 업로드 빈도 차이가 팬과의 친밀도를 빠르게 높인다.

### 핵심 내용

- 미드폼: **주 1회** 생산
- 숏폼: **주 3회**, **주 5회**, 최대 **주 7회** 업로드 가능
- 로열티 쌓는 방법 세 가지:
  1. 자주 얼굴 비추기 — 접촉 빈도가 친밀도를 결정
  2. 댓글 반응을 빠르게 캐치해 영상 제작에 반영 — 잠재 고객이 원하는 주제로 빠른 응답
  3. 챌린지·트렌드 숏폼 — 시청자와 "함께 놀아주는" 분위기 형성 → 심리적 친밀도·회사기 향상

### 강사 비유 / 예시

> "일주일에 한 번 보는 사람과 일주일에 세 번, 다섯 번, 일곱 번 보는 사람 누가 더 빨리 친해지겠냐 이 문제인 거죠."

틱톡·인스타에서는 댓글에 응답하는 형식으로 숏폼을 제작해 로열티를 높이는 사례를 실제 운영 패턴으로 소개.

### 주의 사항

- 정보성 숏폼으로 시작하더라도 챌린지·트렌드 숏폼을 섞으면 팬과의 결속이 더 강해짐
- "롤티" → 로열티 (음성인식 오타)

## 🎯 숏폼 장점 ③ 빠른 실력 상승

> **유형**: 개념
> **타임스탬프**: [02:32] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=152

### 한 줄 요약

숏폼은 주 5회 이상 피드백 루프를 돌릴 수 있어 미드폼 주 1회보다 실력 성장 속도가 압도적으로 빠르다.

### 핵심 내용

- 미드폼: 주 **1회** 제작 → 피드백 **1회**
- 숏폼: 주 **5~7회** 제작 → 피드백 **5~7회** → 수정 사항을 바로 다음 영상에 반영
- 강사 극단 사례: **하루 12개** 숏폼 제작 → 한 달 후 다른 크리에이터와 성장 속도 독보적 차이

### 강사 비유 / 예시

> "저 같은 경우는 하루에도 12개까지 올려봤어요. 그렇게 한 달 하고 나니까 정말 성장 속도가 다른 크리에이터랑 독보적으로 달라지더라고요."

### 주의 사항

- 하루 12개는 강사의 극단 사례이므로 비현실적인 목표로 오해하지 말 것
- 핵심 원리는 "피드백 빈도 = 성장 속도"

## 🎯 정보성 숏폼 3파트 구성 (도입/본문/결론)

> **유형**: 템플릿
> **타임스탬프**: [04:01] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=241

### 한 줄 요약

정보성 숏폼은 도입–본문–결론 3파트로 구성되며, 파트마다 역할이 명확히 다르다.

### 핵심 내용

| 파트 | 역할 | 핵심 기준 |
|------|------|-----------|
| **도입부** | 주의 끌기 | **0.5초~1초** 안에 타겟의 시선 멈추기 (1초도 길다) |
| **본문** | 정보 전달 | 문제 해결 도움 + 충분한 가치 + 경쟁 영상보다 쉽고 빠르고 효과적 |
| **결론** | 행동 유도 | 구독/댓글/미드폼/키 콘텐츠/프로필 링크 중 하나라도 **무조건** 받기 |

### 강사 비유 / 예시

> "쇼츠피드 릴스탭에서 이렇게 넘기고 있을 때, 0.5초 만에 주의를 끌어야 된다라는 점 지금 기억을 해 두셔야 되겠습니다."

> "결론 부분은 행동 버튼을 넣어서 시청자에게 무엇이라도 받아야 된다."

### 주의 사항

- 도입부에서 실패하면 본문·결론이 아무리 좋아도 기회 자체를 잃음
- 결론에서 행동 버튼을 빠뜨리는 것이 초보자의 가장 흔한 실수

## 🎯 정보성 숏폼 제작 단계 개요 (전체 플로우)

> **유형**: 프로세스
> **타임스탬프**: [02:58] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=178

### 한 줄 요약

"정보성 풀링형 숏폼"은 10단계 제작 플로우를 따르며, 원고(템플릿)와 도입부를 먼저 잡는 것이 핵심 순서다.

### 핵심 내용

전체 제작 단계 순서:

1. **주제 선정** (뷰트랩 활용)
2. **원고 틀(템플릿) 선택** — 총 4가지 템플릿 중 선택, 초보자 가이드
3. **자료 조사**
4. **도입부 + 표시 제목 + 썸네일 + 제목 제작** (4개를 한 단계에서 동시 작업)
5. **원고 작성**
6. **콘티(스토리보드)** — 문장별로 어떤 장면을 넣을지 기획
7. **녹음**
8. **촬영**
9. **편집**
10. **업로드**

**썸네일/제목을 앞에 두지 않는 이유**: 숏폼은 쇼츠피드·릴스탭에서 넘기면서 소비되어 노출 대부분이 피드에서 발생 → 도입부(영상 첫 0.5초)가 썸네일 역할을 겸하므로 도입부 작성 시 함께 처리

### 강사 비유 / 예시

> "썸네일 제목보다 원고를 먼저 만들게 되어 있습니다."

콘티에 대한 설명:
> "콘티라는 게 있습니다. 이건 스토리보드라고도 하는데 각 원고의 문장별로 보면서 어떤 장면을 넣을지 기획하는 단계라고 생각하시면 되겠습니다. 이걸 해야 촬영과 편집의 시간이 확 줄어들게 되실 거예요."

### 주의 사항

- 원고 틀(템플릿)은 가이드이므로 의존하면 안 됨 → 강사가 "본인만의 템플릿 만드는 방법"도 이후 강에서 설명
- 콘티 없이 촬영·편집에 들어가면 시간이 대폭 증가함

## 🎯 1단계: 주제 선정 — 뷰트랩 활용 2가지 방법

> **유형**: 프로세스
> **타임스탬프**: [05:07] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=307

### 한 줄 요약

뷰트랩에서 미드폼 주제 찾듯이 숏폼 주제를 고르거나, 쇼츠 필터를 적용해 숏폼 전용 주제를 바로 찾는다.

### 핵심 내용

**방법 1 — 미드폼 주제 탐색과 동일한 방법 적용**
- 뷰트랩에서 평소대로 키워드 검색 후 필터 적용
- 티어도 + 성과도 + 노출 확률 세 가지 기준으로 선정
- 선정한 미드폼 주제를 그대로 숏폼 주제로 풀기

**방법 2 — 쇼츠 전용 필터 적용**
- 뷰트랩 필터에서 **"쇼츠만 보기"** 선택
- 쇼츠 영상들만 표시되는 상태에서 동일하게 티어도 + 성과도 + 노출 확률 기준 적용

### 적용 방법 / 절차

1. 뷰트랩 접속
2. 관심 키워드 검색
3. (방법 1) 일반 필터로 조회 → 티어도/성과도/노출 확률 확인 → 주제 선정 → 해당 주제를 숏폼 버전으로 기획
4. (방법 2) 필터 → **"쇼츠만 보기"** 체크 → 동일 기준으로 주제 선정

### 강사 비유 / 예시

강사 시연 과정:
- 뷰트랩에서 **"퍼스널 컬러"** 검색
- 쇼츠 필터 적용 후 훑어보니 **"웜톤 쿨톤 자가진단법"** 발견

> "저는 사실 퍼스널 컬러를 하나도 모릅니다. 그래서 요걸 일단은 주제로 선정해 봤습니다. 모르는 분야도 숏폼 제작이 된다라는 걸 제가 보여 드리도록 하겠습니다."

### 주의 사항

- 모르는 분야여도 주제 선정 → 자료 조사 순서로 진행하면 제작 가능 (강사의 의도적 시연)
- 뷰트랩 필터 조작이 아직 익숙하지 않다면 미드폼 주제 찾는 방식(방법 1)부터 시작하는 것이 진입 장벽이 낮음

## 관통 메시지 (1강)

1. **"0.5초 안에 주의를 끌어야 한다"** — 숏폼 피드는 도입부 첫 프레임이 전부, 1초도 이미 늦다
2. **"결론에 무조건 행동 버튼을 넣어야 한다"** — 구독/댓글/미드폼/프로필 링크 중 하나라도 반드시 요청
3. **"주 1회 피드백 vs 주 5~7회 피드백"** — 숏폼의 가장 큰 숨은 장점은 빠른 실력 성장
4. **"원고 틀(템플릿)을 먼저, 썸네일 제목은 나중"** — 숏폼은 피드 노출이 주이므로 도입부와 함께 묶어 처리

## 다음 강 연결

2강에서는 제작 단계 **2단계(원고 틀/템플릿 선택)**와 **3단계(자료 조사)**를 다룬다. 강사가 예고한 대로 "퍼스널 컬러 → 웜톤/쿨톤 자가진단법" 주제로 실제 원고를 만들어가는 시연이 이어진다. 초보자를 위한 4가지 원고 틀(템플릿)의 구체적인 내용과 본인만의 템플릿을 만드는 방법도 공개될 예정이다.
