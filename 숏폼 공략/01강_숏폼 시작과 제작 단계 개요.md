# 1강 — 숏폼 시작과 제작 단계 개요

## 🎯 한 줄 요약

숏폼은 원소스 멀티유즈·로열티·빠른 실력 상승이라는 세 가지 장점을 가진 트래픽 확보 수단이다. 정보성 풀링형 숏폼은 도입-본문-결론 3파트로 구성되며, **도입부 0.5초 안에 주의를 끄는 것**이 성패를 가른다.

> [!IMPORTANT]
> **1강의 진짜 메시지: 양이 곧 실력이다.** 미드폼 주 1회 vs 숏폼 주 5~7회 = 피드백 최대 7배.
> 고민할 시간에 일단 만들어라.

---

## ⏱️ 5분 복습 카드

- **숏폼/미드폼** — 이 강의 고유 용어. 짧은 세로형 vs 유튜브 긴 영상 (외부 혼용과 구별)
- **원소스 멀티유즈** — 쇼츠/릴스/틱톡/쓰레드/네이버 클립 동시 업로드 → 단일 플랫폼 리스크 분산
- **피드백 빈도 = 성장 속도** — 주 1회 vs 주 5~7회. 강사는 하루 12개까지 올려 성장 속도 차이를 직접 경험
- **3파트 구조** — 도입(0.5초 주의 끌기) → 본문(정보 전달) → 결론(행동 유도). 직렬 연결 — 도입 실패 시 나머지는 작동 불가
- **제작 10단계** — 주제 선정 → 원고 틀 → 자료 조사 → 도입부+썸네일+제목 → 원고 → 콘티 → 녹음 → 촬영 → 편집 → 업로드
- **뷰트랩 주제 선정 2가지** — 미드폼 주제를 숏폼으로 전환하는 일반 필터 방법 / 쇼츠 전용 필터로 바로 찾는 방법

## 📚 핵심 개념

| 용어 | 정의 |
|------|------|
| **숏폼** | 유튜브 쇼츠·인스타 릴스처럼 짧고 세로형인 영상 포맷 전체 |
| **미드폼** | 유튜브에 올리는 가로 긴 영상 (일반 유튜브 영상) |
| **원소스 멀티유즈** | 숏폼 하나를 쇼츠·릴스·틱톡·쓰레드·네이버 클립에 동시 업로드 |
| **로열티** | 업로드 빈도가 높을수록 쌓이는 팬과의 친밀도·결속 |
| **정보성 풀링형 숏폼** | 도입-본문-결론 3파트로 정보를 전달하는 숏폼 유형 |
| **콘티(스토리보드)** | 원고 문장별로 어떤 장면을 넣을지 기획하는 단계 |
| **뷰트랩** | 주제 선정에 활용하는 유튜브 키워드 분석 도구 |

**이 표의 의미**: 강의 전체를 관통하는 전문 용어 7개다. 특히 "숏폼/미드폼" 구분은 이 강의 고유 정의이므로, 외부에서 쇼트폼·롱폼이 혼용되는 방식과 분리해서 기억해야 한다.

**무게 분배**: 7개 중 당장 가장 중요한 것은 "정보성 풀링형 숏폼"과 "콘티". 초보자가 놓치기 쉬운 두 가지다. 나머지 5개는 이미 익숙한 개념이지만, 이 강의 기준으로 재정의된 의미로 고정하는 게 중요하다.

> [!NOTE]
> 이 강의 시리즈 내에서 "숏폼"과 "미드폼"은 고정 용어다. 음성인식 오타 주의: "쇼폰/초폰/효뽕" → 숏폼 / "위드폼" → 미드폼.

## 🧩 프레임워크·공식

### 숏폼 3대 장점

지금까지 숏폼이 무엇인지 봤다. 그럼 왜 굳이 숏폼을 해야 하는가?

| 장점 | 핵심 메커니즘 | 세부 방법 |
|------|--------------|-----------|
| **원소스 멀티유즈** | 단일 플랫폼 리스크 감소 + 신규 타겟층 발굴 | 쇼츠·릴스·틱톡·쓰레드·네이버 클립 동시 업로드 |
| **로열티 쌓기** | 접촉 빈도 ↑ → 팬 친밀도 ↑ | ① 자주 얼굴 비추기 ② 댓글 반응 캐치 → 바로 다음 영상에 반영 ③ 챌린지·트렌드 숏폼으로 "함께 놀아주기" |
| **빠른 실력 상승** | 피드백 빈도 = 성장 속도 | 주 1회(미드폼) vs 주 5~7회(숏폼) → 최대 7배 피드백 루프 |

**이 표의 의미**: 3가지 장점이 독립적으로 존재하는 것이 아니라 서로 강화된다. 자주 올릴수록(장점 3) 팬과 더 자주 접촉하고(장점 2), 여러 플랫폼에 동시 배포할수록(장점 1) 실력 성장의 무대가 넓어진다.

**각 장점의 "왜?"**:
- 원소스 멀티유즈: 단일 플랫폼 알고리즘 의존이 채널 생사를 결정한다. 분산이 곧 안전망이다. 한 플랫폼의 변동·계정 정지에 채널 전부가 흔들리지 않게 하는 보험이다. 강사가 특별히 강조한 플랫폼은 네이버 클립 — 네이버 검색 유입까지 잡을 수 있는 기회다.
- 로열티 쌓기: 강사의 말을 그대로 옮기면, "일주일에 한 번 보는 사람과 일주일에 세 번, 다섯 번, 일곱 번 보는 사람 누가 더 빨리 친해지겠냐 이 문제인 거죠." 댓글 반응을 캐치해 다음 영상에 바로 반영하는 것이 잠재 고객이 원하는 주제로 빠르게 응답하는 방식이다.
- 빠른 실력 상승: 강사 본인의 극단 사례 — 하루 12개 숏폼을 올렸더니 한 달 후 다른 크리에이터와 성장 속도가 "독보적으로" 달라졌다. 하루 12개는 비현실적인 목표가 아닌 원리를 보여주는 데이터다.

**인과 사슬**:
```
피드백 빈도 ↑ (주 5~7회)
  → 수정 포인트 발견 속도 ↑
  → 다음 영상 즉시 반영
  → 실력 성장 가속
∴ 고민할 시간에 영상 1개 더 올리는 것이 답
```

### 정보성 숏폼 3파트 구조

3대 장점이 왜인지 알았다면, 이제 실제 숏폼은 어떤 구조로 만드는가?

| 파트 | 역할 | 핵심 기준 |
|------|------|-----------|
| **도입부** | 주의 끌기 | 0.5~1초 안에 타겟의 시선을 멈추게 함 (1초도 이미 늦다) |
| **본문** | 정보 전달 | 문제 해결 + 충분한 가치 + 경쟁 영상보다 쉽고 빠르고 효과적 |
| **결론** | 행동 유도 | 구독/댓글/미드폼/키 콘텐츠/프로필 링크 중 하나라도 **무조건** 받기 |

**이 표의 의미**: 숏폼 한 편은 사실상 세 모듈의 직렬 연결이다. 한 모듈 실패 시 다음 모듈은 작동하지 않는다. 도입부 실패면 본문이 아무리 좋아도 닿지 않는다.

**무게 분배**: 시간으로 보면 도입부는 영상 전체의 5% 이하지만, 노력은 50%를 써야 한다. 본문과 결론은 도입부가 통과한 시청자에게만 의미가 있다.

**실전 적용**: 영상 1편을 만들 때 도입부 멘트와 첫 화면을 가장 마지막에 다듬는 것이 아니라 가장 먼저 확정한다. "이 도입부면 사람이 멈출까?"가 통과하기 전엔 본문 작성에 들어가지 말 것.

**인과 사슬**:
```
도입부 약함 → 0.5초 이탈 → 알고리즘 추천 X
             → 노출 0 → 본문 가치 무용지물
∴ 도입부 0.5초 = 모든 것
```

> [!IMPORTANT]
> 도입부에서 실패하면 본문·결론이 아무리 좋아도 기회 자체를 잃는다. 1초도 이미 늦다.

### 제작 10단계 플로우

3파트 구조를 알았다면, 실제로 어떤 순서로 만드는가?

```
① 주제 선정 (뷰트랩)
② 원고 틀(템플릿) 선택 — 4가지 중 선택
③ 자료 조사
④ 도입부 + 표시 제목 + 썸네일 + 제목 제작  ← 4개 동시 작업
⑤ 원고 작성
⑥ 콘티(스토리보드)
⑦ 녹음
⑧ 촬영
⑨ 편집
⑩ 업로드
```

**왜 썸네일·제목이 ④에 있는가**: 숏폼은 쇼츠피드·릴스탭에서 넘기면서 소비된다. 노출의 대부분이 피드에서 발생한다는 뜻이다. 따라서 도입부(영상 첫 0.5초)가 썸네일 역할을 겸한다. 도입부와 썸네일·제목을 한 단계에서 동시에 처리하는 것이 효율적이다.

**왜 콘티(⑥)가 별도 단계로 있는가**: 강사 설명 그대로 — "각 원고의 문장별로 보면서 어떤 장면을 넣을지 기획하는 단계다. 이걸 해야 촬영과 편집의 시간이 확 줄어든다." 콘티 없이 촬영에 들어가면 편집 단계에서 시간이 대폭 증가한다.

**실전 적용**: ① 주제 선정과 ④ 도입부 확정이 전체 품질을 좌우하는 두 병목이다. 이 두 단계에 가장 많은 시간을 배분하고, ⑦~⑨ 녹음·촬영·편집은 콘티가 있으면 기계적으로 따라가면 된다.

### 뷰트랩 주제 선정 2가지 방법

| 방법 | 절차 | 특징 |
|------|------|------|
| **방법 1** 일반 필터 | 키워드 검색 → 티어도+성과도+노출확률 기준으로 주제 선정 → 그 주제를 숏폼으로 기획 | 진입 장벽 낮음. 미드폼 주제 찾는 방식과 동일 |
| **방법 2** 쇼츠 전용 | 필터에서 "쇼츠만 보기" 체크 → 동일 기준으로 숏폼 전용 주제 바로 선정 | 숏폼에 이미 검증된 주제를 바로 확인 |

**이 표의 의미**: 두 방법 모두 뷰트랩에서 출발하지만, 방법 1은 "미드폼 주제를 숏폼으로 번역"하는 경로이고 방법 2는 "숏폼 전용 주제를 직접 발굴"하는 경로다.

**어떻게 적용하는가**: 뷰트랩이 처음이라면 방법 1로 시작한다. 이미 미드폼 주제 선정을 해봤다면 동일한 루틴에서 숏폼도 선정할 수 있다. 방법 2는 "쇼츠만 보기" 필터 하나만 추가로 누르면 되므로 익숙해지면 방법 2를 병행하는 것이 효율적이다.

**구체 사례 (강사 시연)**: 강사는 뷰트랩에서 "퍼스널 컬러"를 검색하고 쇼츠 필터를 적용했더니 "웜톤 쿨톤 자가진단법"이 나왔다고 설명했다. 이어서 "저는 사실 퍼스널 컬러를 하나도 모릅니다. 모르는 분야도 숏폼 제작이 된다는 걸 보여드리겠습니다"라고 덧붙였다. 주제 선정과 자료 조사가 분리된 순서이기 때문에 가능한 방식이다.

**놓치기 쉬운 점**: 방법 2는 이미 쇼츠에서 성과가 난 주제만 표시하므로 경쟁 강도도 함께 올라간다. 방법 1처럼 미드폼 주제를 숏폼으로 옮기면 상대적으로 경쟁이 낮은 블루오션 주제를 찾을 수 있다.

### 이 강의 전체 로드맵

강사: 60만 팔로워 계정 운영 출신 김준석 트레이너 / 대상: 숏폼 왕초보~고수

```
파트 1  숏폼의 전체 흐름 소개          ← 1강 (현재)
파트 2  숏폼 제작 단계 세부             (주제 선정 → 업로드 10단계)
파트 3  숏폼 끝내기 (자가 성장 루틴)
파트 4  키용 숏폼 제작 + 운영 전략
```

**이 강의를 들어야 하는 두 가지 상황**: ① 숏폼이 막막한 초보 — 아직 시작을 못 했거나 뭘 해야 할지 모르는 경우. ② 수익화 구조는 완성됐지만 상품창 개선·객단가 올리기 작업에 치여 미드폼 제작 시간이 부족한 경우 — 숏폼이 트래픽 보완 수단이 된다.

## ⚠️ 흔한 실수

**실수 1 — 결론에 행동 버튼 누락**

❌ 영상을 끝맺는 말만 하고 닫기. "이상입니다", "도움이 됐으면 좋겠어요"
✅ 구독·댓글·미드폼 링크·프로필 링크 중 최소 하나를 명시적으로 요청

→ 왜 차이가 나는가: 시청자는 아무것도 안 하는 것이 기본값이다. 행동 버튼 없이 영상이 끝나면 이탈이 기본이다. "무조건 하나라도 받아야 한다"는 강사의 표현이 이 원리를 요약한다. 초보자가 가장 자주 범하는 실수.

**실수 2 — 도입부를 길게 시작**

❌ "안녕하세요, 오늘은 퍼스널 컬러에 대해 알아보겠습니다." (인사·소개로 시작)
✅ "이거 모르면 평생 손해 보는 웜톤 쿨톤 구분법" (즉시 후킹)

→ 왜 차이가 나는가: 쇼츠 피드에서 시청자는 손가락이 이미 위로 올라가 있는 상태로 영상을 만난다. 0.5초 안에 손가락을 멈출 이유를 줘야 한다. 미드폼 출신 크리에이터가 숏폼에서도 인사·소개로 시작하는 패턴이 가장 빈번하다.

**실수 3 — "양 vs 질" 고민으로 시작 못 함**

❌ "퀄리티가 안 되면 올리면 안 된다" → 주 1회도 못 올림
✅ "일단 올린다 → 피드백 받는다 → 다음 편에 반영한다"

→ 왜 차이가 나는가: 숏폼의 핵심 가치는 피드백 빈도에서 나온다. 완성도를 올리는 가장 빠른 길이 "많이 올리기"다. 주 5~7회 업로드가 부담스러워 시작 자체를 미루는 것이 실력 상승의 가장 큰 적이다.

**실수 4 — 콘티 없이 촬영·편집 진입**

❌ 원고만 쓰고 바로 촬영 → 편집할 때 "이 장면이 없다"를 뒤늦게 발견 → 재촬영
✅ 원고 문장별로 장면 지정(콘티) → 촬영 1회 완료 → 편집 속도 대폭 단축

→ 왜 차이가 나는가: 콘티 없이 촬영하면 편집 단계에서 빠진 장면을 발견하고 재촬영이 발생한다. 콘티는 번거로운 준비가 아니라 총 제작 시간을 줄이는 도구다.
