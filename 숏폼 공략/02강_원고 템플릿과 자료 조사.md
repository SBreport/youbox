# 2강 — 원고 템플릿과 자료 조사

## 🎯 한 줄 요약

숏폼 원고는 백지에서 쓰는 게 아니다. 4가지 템플릿 중 하나를 먼저 확정하고, 그 틀의 각 칸을 채우기 위한 자료만 조사한다. 자료는 "타겟 문제 해결"과 "경쟁 대비 차별화"라는 2가지 관문을 통과한 것만 쓴다. 국내에 없으면 외국까지 뒤진다.

> [!IMPORTANT]
> **2강의 진짜 메시지: 빈 화면 앞에서 막히는 이유는 틀이 없기 때문이다.** 템플릿 먼저, 자료 조사 나중. 조사 범위는 템플릿 칸에 필요한 것만으로 한정한다.

---

## ⏱️ 5분 복습 카드

- **4가지 템플릿** — 나열형 / 순서형 / 스토리형 / 주장 설득형. 모든 숏폼 원고는 이 4개 중 하나에 해당한다
- **혜택 vs 장점** — 기능 → 장점 → 혜택 순으로 추상화 수준이 높아진다. 원고는 반드시 혜택(삶의 긍정적 변화)까지 이어야 한다
- **추가 요소 5종** — 주의사항 / 연관 상품 / 추가 활용 꿀팁 / 구매 꿀팁 / 반론 대안. 전부 넣는 게 아니라 자연스럽게 어울리는 것만 선택
- **명분 담은 행동 버튼** — "구독해 주세요"가 아니라 "앞으로 이런 가치를 계속 드릴 거니 구독해 주세요"
- **자료 조사 2관문** — ① 타겟 문제에 직접 도움 / ② 경쟁 영상보다 더 도움. 둘 다 YES가 아니면 버린다
- **외국 정보** — 국내 정보가 평이하다고 느껴지는 순간 영어·스페인어 검색으로 전환. 가장 쉬운 차별화 레버

## 📚 핵심 개념

| 용어 | 정의 |
|------|------|
| **나열형** | 순서 없이 방법·제품을 딱딱 나열하며 각 항목마다 장점·혜택을 붙이는 구조 |
| **순서형** | 단계를 시간 순서대로 나열하고 장점·혜택은 전체 완료 후에 붙이는 구조 |
| **스토리형** | 상황 → 해결 → 교훈 → 혜택으로 이어지는 스토리 전달 구조 |
| **주장 설득형** | 주장 → 근거 → 예시 → 반론 대안 → 혜택으로 납득시키는 구조 |
| **혜택** | 장점이 실현됐을 때 시청자의 삶에 구체적으로 펼쳐지는 긍정적 변화 |
| **명분 담은 행동 버튼** | 결론부에서 구독·좋아요 요청 앞에 지속 제공 가치를 이유로 붙이는 것 |
| **추가 요소** | 주의사항 / 연관 상품 / 추가 활용 꿀팁 / 구매 꿀팁 / 반론 대안 — 선택 삽입 |
| **카피** | 경쟁 영상의 원고를 그대로 베끼는 행위 — 절대 금지 |

**이 표의 의미**: 2강은 "원고를 어떤 틀로 쓸 것인가"와 "그 틀을 채울 재료를 어디서 구할 것인가" 두 파트로 구성된다. 용어 8개는 전부 이 두 축에 해당한다.

**무게 분배**: 당장 중요한 두 가지는 "혜택"과 "카피 금지". 나열형·순서형 구조는 비슷해 보이지만 장점·혜택 위치가 다르다는 점이 핵심 차이다. 명분 담은 행동 버튼은 초보자가 가장 빠뜨리기 쉬운 항목이다.

**놓치기 쉬운 점**: "혜택"이 빠지면 시청자가 행동하지 않는다. 장점까지만 쓰고 끝내는 원고가 왕초보의 가장 흔한 패턴이다.

## 🧩 프레임워크·공식

### 원고 템플릿 4가지

4가지 템플릿을 보기 전에, 먼저 원고 구조를 왜 미리 고르는지부터 이해해야 한다.

**왜 템플릿을 먼저 고르는가**: 콘텐츠 유형이 결정되면 "이 칸에 뭘 넣을까"라는 목적이 생긴다. 목적이 생기면 자료 조사 범위가 자동으로 좁혀진다. 무한 조사의 늪에 빠지지 않는 유일한 방법이다.

```
템플릿 확정
  → 각 칸에 필요한 정보 목록 생성
  → 그 목록에 맞는 자료만 조사
  → 초안 작성 속도 대폭 단축
∴ 백지에서 쓰지 말 것. 틀부터 고를 것.
```

| 템플릿 | 본문 구조 | 장점·혜택 위치 | 대표 카테고리 |
|--------|-----------|----------------|---------------|
| **나열형** | 방법·제품을 순서 없이 나열 | 각 항목 바로 뒤 | 정보성 전반 |
| **순서형** | 단계를 시간순으로 나열 | 전체 완료 후 (특별 단계는 예외) | 요리·운동·과정 |
| **스토리형** | 상황 → 해결 → 교훈 → 혜택 | 교훈 뒤에 혜택 | 자기계발 |
| **주장 설득형** | 주장 → 근거 → 예시 → 반론 → 혜택 | 반론 대안 뒤에 혜택 | 의견·주장성 |

**이 표의 의미**: 4가지 모두 도입(표시 제목 + 후킹 멘트)과 결론(명분 담은 행동 버튼)은 동일하다. 차이는 본문의 흐름과 장점·혜택을 붙이는 위치다.

**무게 분배**: 초보자에게 가장 많이 쓰이는 순서는 나열형 → 순서형 → 스토리형 → 주장 설득형이다. 나열형이 가장 진입 장벽이 낮고 스토리형과 주장 설득형은 자기 이야기가 있어야 강해진다.

**실전 적용**: 주제를 확정했다면 "이 주제는 순서가 있는가 없는가"로 먼저 분류한다. 있으면 순서형, 없으면 나열형. 교훈을 전달하는 주제면 스토리형, 의견·주장성이라면 주장 설득형.

**놓치기 쉬운 점**: 나열형과 순서형의 구조는 비슷해 보여도 장점·혜택 위치가 다르다. 나열형은 각 항목 바로 뒤, 순서형은 전체 단계 완료 후다. 이 위치를 바꾸면 시청자의 호기심이 끊긴다.

> [!IMPORTANT]
> 강사 인용: "아줌마 꿀팁 다섯 가지 알려드릴게요. 나이서 추천 꿀템 세 가지. 자존감 올리는 다섯 가지 방법. 이런 식으로 진행되는 게 나열형입니다." 이것이 숏폼 원고의 가장 기본 뼈대다.

### 혜택 vs 장점 vs 기능 — 3단계 추상화

| 구분 | 설명 | 내 집 마련 서비스 예시 |
|------|------|----------------------|
| **기능** | 제품·서비스가 할 수 있는 것 | — |
| **장점** | 기능이 가져다주는 이점 | 부동산 중개 선택, 매매 찾기, 매매 합의를 도와줌 |
| **혜택** | 삶에 일어나는 긍정적 변화 | 햇빛이 비치는 일실에서 사랑하는 아내·두 자녀와 따뜻한 식사를 하게 됨 |

**이 표의 의미**: 기능에서 멈추면 설명서, 장점에서 멈추면 광고, 혜택까지 이어야 비로소 시청자가 움직인다.

**왜 혜택까지 이어야 하는가**: 사람은 정보를 소비하는 게 아니라 변화를 원한다. 장점은 "좋겠다"로 끝나지만 혜택은 "나도 저렇게 되고 싶다"를 만든다. 행동 유발 여부가 여기서 갈린다.

**실전 적용**: 원고를 쓸 때 장점을 적은 뒤 "그래서 내 삶이 어떻게 달라지는가?"를 스스로 질문한다. 그 답이 혜택이다. 강사 표현 그대로 — "삶의 긍정적인 변화가 어떻게 일어날 것인가를 말해주시면 됩니다."

**놓치기 쉬운 점**: 원고에서 장점만 쓰는 패턴은 제작자 입장에서 쓰기 쉽기 때문에 반복된다. 시청자 입장으로 전환해서 "내 삶에 뭐가 달라지지?"를 대입하는 습관이 필요하다.

### 추가 요소 5종

본문의 핵심이 채워졌다면, 다음은 정보 가치를 높이는 선택 요소들이다.

| 추가 요소 | 설명 | 예시 |
|-----------|------|------|
| **주의사항** | 시청자가 걱정할 수 있는 부분 | "이 방법은 민감성 피부에는 주의하세요" |
| **연관 상품** | 방법 활용 시 도움되는 상품 (내 판매 상품 아니어도 됨) | 요리 레시피 + 특정 브랜드 팬 추천 |
| **추가 활용 꿀팁** | 소개한 상품·서비스의 다른 활용법 | 다이소 방향제를 소개하면서 "신발장에도 너무 좋다" 추가 |
| **구매 꿀팁** | 할인 코드, 구매 시점, 채널 등 | "이 할인 코드 입력하면 20% 할인" |
| **반론 대안** | 경쟁·관련 영상 댓글에서 수집한 반론을 선제 해소 | 반론 댓글이 내 영상에 달리지 않게 차단 |

**이 표의 의미**: 5종 모두 넣으라는 목록이 아니다. 콘텐츠에 자연스럽게 녹아드는 것만 골라 쓴다.

**왜 반론 대안이 강력한가**: 강사 인용 — "반론 있는 댓글들을 수집해서 내가 미리 영상에서 녹여주면 내 댓글에는 그런 반론 댓글이 없을 것이고 아주 스무스하게 영상이 진행됩니다." 댓글 관리 비용을 원고 단계에서 선제 해결하는 방식이다.

**실전 적용**: 강사가 든 "다이소 방향제 + 신발장에도 너무 좋다" 사례처럼, 추가 활용 꿀팁 하나가 "정말 가치가 더 올라간다"는 반응을 만든다. 본문이 짧아서 영상이 아쉬울 때 시도해볼 첫 번째 요소다.

**놓치기 쉬운 점**: 반론 대안은 경쟁 영상 댓글을 먼저 탐색해야 발굴된다. 자료 조사 단계(댓글 소스)와 연결되는 이유가 여기에 있다.

### 명분 담은 행동 버튼

| 구분 | 예시 |
|------|------|
| ❌ 나쁜 예 | "구독, 좋아요 부탁드립니다" |
| ✅ 좋은 예 | "계속해서 살림에 200% 도움되는 제품 추천드릴 거니 구독 부탁드려요" |

**이 표의 의미**: 차이는 "이유"가 있느냐 없느냐다. 구독 전환율에 직접 영향을 미치는 단 하나의 요소다.

**왜 명분이 필요한가**: 강사 인용 — "그냥 구독, 좋아요보다는 계속해서 살림에 200% 도움되는 제품 추천드릴 거니 구독 부탁드려요가 훨씬 더 구독 전환율에 있어서 도움이 되겠죠." 시청자에게 "왜 구독해야 하는가"의 이유를 먼저 주는 것이다.

**실전 적용**: 내 채널이 앞으로 시청자에게 어떤 가치를 지속 제공할지 한 문장으로 정의한다. 그 문장을 구독 요청 앞에 붙이면 끝이다. 4가지 템플릿 모두의 결론에 공통으로 들어간다.

### 자료 조사 2관문

정보를 어디서 구할지 보기 전에, 수집한 정보를 거르는 기준부터 잡는다.

| # | 질문 | 목적 |
|---|------|------|
| ① | 타겟의 문제 해결에 **직접적으로** 도움을 주는 정보인가? | 공유·저장 유발 |
| ② | **경쟁 영상보다** 더 도움을 주는 정보인가? | 정보 가치 차별화 |

**이 표의 의미**: ①은 관련성 필터, ②는 차별화 필터다. 둘 다 통과해야만 원고에 쓸 수 있다.

**왜 경쟁 영상 기준이 있어야 하는가**: 강사 인용 — "여기서도 알 수 있고 저기서도 알 수 있는 그런 정보라면 시청자들께서 내 영상을 볼 이유가 정말 없습니다." 구독자 많은 채널과 동일한 정보 수준이면 시청자는 더 큰 채널을 선택한다.

**실전 적용**: 경쟁 영상을 먼저 3~5개 분석해야 ②번 기준이 생긴다. "3분 락스 청소법"처럼 같은 정보에 더 신속한 방법이 추가되는 것만으로도 공유·저장 확률이 올라간다.

### 자료 조사 소스 4가지

2관문 기준을 확인했다면, 이제 어디서 정보를 구하는지 본다.

| 소스 | 수집 방법 | 특징 |
|------|-----------|------|
| **① 댓글** | 동일 주제 영상 3~5개 댓글 탐색 / 좋아요 10개 이상 우선 | 공감 요소·반론·꿀팁 동시 채굴 가능 |
| **② 인터넷 사이트** | 구글·네이버·구글 북스·전문 사이트 | 챗GPT는 아이디어 발산용으로만 — 환각 주의 |
| **③ 커뮤니티** | 주제 관련 커뮤니티 검색창에 키워드 입력 | 실사용자 경험담·비교 후기 풍부 |
| **④ 외국 정보** | 영어·스페인어 검색 / 뷰트랩 외국어 검색 병행 | 국내에 없는 정보로 압도적 차별화 가능 |

**이 표의 의미**: 4가지 소스는 쓰는 순서보다 "국내 자료가 평이하다고 느껴지는 순간 즉시 ④로 전환"하는 판단이 더 중요하다.

**왜 외국 정보가 강조되는가**: 강사가 2022년부터 적극 활용해온 차별화 전략이다. 강사 인용 — "탄냄비 세척법 주제를 선정했는데 스페인어로 검색하니까 흑설탕을 이용하는 방법이랑 건조기 시트를 활용해서 탄냄비를 세척하는 방법이 있더라고요. 구글에서 확인하니 한국의 몇몇 분들만 그 정보를 전달하고 계시더라고요. 그러면 이걸 내가 유튜브에서 처음 다루게 되었을 때 사람들은 '와, 고맙다'라는 반응이 나올 수가 있겠죠." 검색 언어 하나만 바꿔도 경쟁 없는 정보를 찾을 수 있다.

**왜 챗GPT를 직접 원고에 쓰면 안 되는가**: 강사 인용 — "챗GPT 답변 그대로 원고 본문에 쓰시는 건 추천하지 않습니다. 환각이 있기 때문에 잘못된 정보가 많습니다. 양산형 공장 쇼츠로 비춰질 수 있기 때문에 주의해 주셔야 됩니다." 아이디어 발산과 방향 설정에만 쓰고, 사실 정보는 원본 출처 교차 확인이 필수다.

**놓치기 쉬운 점**: 외국 정보라도 국내 상황(성분 규제, 문화 차이)에 맞는지 검증해야 한다. 정보만 가져오는 게 아니라 국내 맥락에서 재구성하는 작업이 필요하다.

## ⚠️ 흔한 실수

**실수 1 — 혜택 없이 장점에서 멈추기**

❌ "이 방법을 쓰면 청소 시간이 줄어들어요." (장점에서 종료)
✅ "이 방법을 쓰면 청소에 쏟던 하루 30분을 돌려받아 퇴근 후 한 시간이 온전히 내 것이 됩니다." (혜택까지)

→ 왜 차이가 나는가: 장점은 "좋겠다"로 끝나고 혜택은 "갖고 싶다"를 만든다. 행동 유발 여부가 여기서 갈린다. 장점에서 멈추는 것은 제작자 관점에서 쓰기 쉽기 때문에 반복되는 패턴이다.

**실수 2 — 명분 없는 행동 버튼**

❌ "구독, 좋아요 부탁드립니다." (이유 없음)
✅ "계속해서 살림에 200% 도움되는 제품 추천드릴 거니 구독 부탁드려요." (명분 선행)

→ 왜 차이가 나는가: 시청자는 아무것도 안 하는 것이 기본값이다. 구독할 이유를 먼저 주지 않으면 행동이 일어나지 않는다. 4가지 템플릿 모두의 결론에 필수로 들어가야 할 항목인데도 초보자가 가장 빠뜨리기 쉽다.

**실수 3 — 자료 조사 범위 초과**

❌ 관심 가는 정보를 모두 수집 → 1~2시간 조사 후 원고 시작도 못 함
✅ 템플릿 칸에 필요한 항목 목록 먼저 작성 → 해당 칸이 채워지면 즉시 종료

→ 왜 차이가 나는가: 목적 없는 조사는 끝이 없다. 강사 인용 — "자료 조사하다 보면 시간을 무한정으로 쓰게 될 수도 있어요. 그래서 템플릿에 넣을 요소들에 대해서만 자료 수집을 해 주시면 초안 작업하는 데 속도가 빨라지실 겁니다." 템플릿 칸이 채워진 순간이 조사 완료 시점이다.

**실수 4 — 국내 자료만 탐색하고 평이한 정보로 원고 완성**

❌ 국내 검색만 하고 "이 정도면 됐겠지"로 원고 제출
✅ 국내 자료가 평이하다고 느껴지는 순간 즉시 영어·스페인어 검색으로 전환

→ 왜 차이가 나는가: 국내 자료는 이미 다수 크리에이터가 탐색한 정보다. 동일한 자료 풀에서 경쟁하는 한 차별화는 불가능하다. 검색 언어 하나만 바꿔도 경쟁 없는 정보를 찾을 수 있다.
