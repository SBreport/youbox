## 🎯 원고 템플릿 ① 나열형

### 한 줄 요약

제품 소개나 방법을 알려줄 때 쓰는 가장 기본적인 정보성 숏폼 구조.

### 핵심 내용

| 구성 | 내용 |
|------|------|
| 도입 | 표시 제목 + 공감·후킹 멘트 (문제 제시 또는 유익 제시) |
| 본문 | 방법·제품 나열 + 각각의 장점·혜택 언급 |
| (선택) 추가 요소 | 주의사항 / 연관 상품 / 추가 활용 꿀팁 / 구매 꿀팁 / 반론 대안 |
| 결론 | 명분 담은 행동 버튼 |

### 강사 비유 / 예시

> "아줌단는 꿀팁 다섯 가지 알려 드릴게요. 나이서 추천 꿀템 세 가지 알려 드리도록 하겠습니다. 자존감 올리는 다섯 가지 방법 알려 드리겠습니다. 이런 식으로 진행되는 게 나열형이라고 생각하시면 되겠습니다."

### 적용 방법 / 절차

1. 표시 제목 결정 (썸네일·자막에 쓰일 제목)
2. 공감 또는 후킹 멘트 작성 — 시청자가 겪는 문제 또는 얻을 유익 제시
3. 방법·제품을 **순서 없이** 딱딱 나열하면서 각 항목마다 장점과 혜택 언급
4. 필요 시 추가 요소 삽입 (아래 별도 카드 참고)
5. 결론에서 명분 담은 행동 버튼 삽입

### 주의 사항

- 나열 항목은 독립적이어야 하며, 순서가 바뀌어도 의미가 통해야 함 (순서 의존성 있으면 순서형으로 전환)

### 한 줄 요약

### 핵심 내용

| 구성 | 내용 |
|------|------|

| 본문 예외 | 특별한 단계가 있으면 그 단계에 한해서 장점·혜택을 바로 붙임 |

### 강사 비유 / 예시

> "이렇게 단계별로 전부 다 알려주고 나서 그다음에 장점과 혜택을 뒤에 붙여 주시면 되겠습니다."

### 적용 방법 / 절차

1. 각 단계를 시간·과정 순서대로 나열
2. 전체 단계를 마친 뒤 장점과 혜택 언급
3. 중간에 특별히 강조해야 할 단계가 있으면, 그 단계 바로 뒤에 장점·혜택 삽입
4. 결론에서 명분 담은 행동 버튼

### 주의 사항

- 나열형과 도입부 구조는 동일하지만, 본문의 **장점·혜택 위치가 다름** — 나열형은 각 항목 뒤, 순서형은 전체 완료 뒤

## 🎯 원고 템플릿 ④ 주장 설득형

정보를 납득시켜야 할 때 쓰는 구조. 5주차 원고의 짧은 버전.

### 핵심 내용

| 구성 | 내용 |
|------|------|
| 도입 | 흥미로운 주장 (또는 일반론에 대한 반론 — 난도 높음) |
| 본문 | ① 유의미한 근거 (데이터·증거·이유) → ② 구체적 예시 (개인 체험담 권장) → ③ 반론 대안 (반론이 예상될 때) → ④ 시청자 혜택 |
| 결론 | 명분 담은 행동 버튼 |

### 강사 비유 / 예시

> "흥미로운 주장이 제일 좋고 그다음에 일반론에 대한 반론, 리스크가 크긴 하지만 내가 할 수 있다면 하는 게 좋겠습니다."

> "저는 개인적인 체험담이 제일 좋다고 말씀드리도록 하겠습니다. 숏폼 같은 경우는 롤티 올리는 데 좋죠. 근데 내 이야기까지 넣으면 더 좋단 말이에요."

### 적용 방법 / 절차

1. 도입에서 시청자가 멈출 만한 **흥미로운 주장** 선언
2. 근거를 데이터·증거·개인 이유로 뒷받침
3. 개인 체험담 또는 지인·역사적 사례로 구체화
4. 반론이 예상되면 구체적 예시 직후에 반론 대안 삽입
5. 시청자가 실천했을 때 얻는 혜택 언급
6. 결론에서 명분 담은 행동 버튼

### 주의 사항

- 일반론 반론은 난도가 높으므로 왕초보 단계에서는 **흥미로운 주장**으로 시작 권장
- 중수·고수가 되면 세세한 순서를 자신만의 방식으로 바꿔도 무방

## 🎯 혜택 vs 장점 vs 기능

> **유형**: 개념
> **타임스탬프**: [07:12] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=432

### 한 줄 요약

기능 → 장점 → 혜택 순으로 추상화 수준이 높아지며, 원고에서 혜택까지 연결해야 시청자가 행동한다.

### 핵심 내용

| 구분 | 설명 | 내집 마련 서비스 예시 |
|------|------|----------------------|
| 기능 | 제품·서비스가 할 수 있는 것 | — |
| 장점 | 기능이 가져다주는 이점 | 부동산 중계 선택, 매매 찾기, 매매 합의를 도와줌 |
| **혜택** | 삶에 일어나는 긍정적 변화 | 햇빛이 비치는 일실에서 사랑하는 아내·두 자녀와 따뜻한 식사를 하게 됨 |

### 강사 비유 / 예시

> "삶의 긍정적인 변화가 어떻게 일어날 것인가를 말해 주시면 됩니다."

### 적용 방법 / 절차

1. 내가 소개할 방법·제품의 기능 나열
2. 각 기능이 가져다주는 장점으로 변환
3. 장점이 실현되었을 때 시청자의 삶에 구체적으로 어떤 장면이 펼쳐지는지 **혜택**으로 기술

### 주의 사항

- 원고에서 장점에서 멈추면 안 됨 — 반드시 혜택(삶의 긍정적 변화)까지 이어줘야 행동 유발

> "장용 다이소 방향제를 추천해 주고 있었습니다. 근데 추가 활용 꿀팁으로 신발장에도 너무 좋다라고 말해 주면, 사람들도 '어, 이런 활용법도 있어' 하면서 정말 가치가 더 올라가겠죠."

> "반론 있는 댓글들을 수집해서 내가 미리 영상에서 녹여 주면 내 댓글에는 그런 반론 댓글이 없을 것이고 아주 스무스하게 영상이 진행이 가능하겠죠."

3. 모두 넣을 필요 없음 — 콘텐츠에 자연스럽게 어울리는 것만 선택

### 주의 사항

- 추가 요소를 억지로 넣으면 영상이 늘어짐 — **자연스럽게 녹아드는 것만** 선택

## 🎯 명분 담은 행동 버튼

> **유형**: 개념
> **타임스탬프**: [08:30] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=510

### 한 줄 요약

결론부의 구독·좋아요 요청은 단순 요청보다 명분(이유)을 붙여야 전환율이 오른다.

### 핵심 내용

| 구분 | 예시 |
|------|------|
| 나쁜 예 | "구독, 좋아요 부탁드립니다" |
| 좋은 예 | "계속해서 살림에 **200%** 도움되는 제품 추천드릴 거니 구독 부탁드려요" |

### 강사 비유 / 예시

> "그냥 구독, 좋아요보다는 계속해서 살림에 200% 도움되는 제품 추천드릴 때 되니 구독 부탁드려가 훨씬 더 구독 전환율에 있어서 도움이 되겠죠."

### 적용 방법 / 절차

1. 내 채널이 앞으로 시청자에게 어떤 가치를 지속적으로 제공할지 정의
2. 그 가치를 한 문장으로 압축하여 구독 요청 앞에 붙임
3. 4가지 템플릿 모두 결론에 필수로 삽입

### 주의 사항

- 모든 템플릿의 결론에 공통으로 들어가는 **필수** 요소

## 🎯 자료 조사 핵심 질문 2가지 (관문)

> **유형**: 체크리스트
> **타임스탬프**: [11:07] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=667

### 한 줄 요약

자료 조사에서 수집하는 모든 정보는 이 **2가지 관문**을 통과해야만 원고에 쓸 수 있다.

### 핵심 내용

| # | 질문 | 목적 |
|---|------|------|
| ① | 타겟의 문제 해결에 **직접적으로** 도움을 주는 정보인가? | 공유·저장 유발 |
| ② | **경쟁 영상보다** 더 도움을 주는 정보인가? | 정보 가치 차별화 → 공유·저장 확률 상승 |

### 강사 비유 / 예시

> "여기서도 알 수 있고 저기서도 알 수 있는 그런 정보라면 나도 그냥 똑같은 정보로 다룬다고 했을 때 시청자들께서 내 영상을 볼 이유가 정말 없습니다."

> "그냥 락스 청소법이 아니라 더 신속하게 될 수 있는 **3분 락스 청소법**이라면 자료를 알려줬을 때 사람들이 더 정보 가치를 높게 보고 공유·저장을 해 주겠죠."

### 적용 방법 / 절차

1. 자료 조사로 정보를 수집할 때마다 두 질문 자가 체크

### 핵심 내용

|----------|------|
| 시간 관리 | 자료 조사에 시간을 무한정 쓰지 말 것 |
| 범위 한정 | 템플릿에 필요한 요소 (장점, 소개, 혜택 등)에 한정해서만 수집 |

### 강사 비유 / 예시

> "자료 조사하다 보면 시간을 무한정으로 쓰게 될 수도 있어요. 그래서 템플릿에 넣을 요소들, 우리 장점·소개·혜택 그런 것들 그런 거에 대해서만 자료 수집을 해 주시면 초안 작업하는 데 있어서 속도가 빨라지실 겁니다."

> "원고를 그대로 카피해서 쓰겠다는 뜻이 아니고, 원고에 대해서 자료 조사하자는 뜻입니다. 그러니까 절대 카피는 하시면 안 되겠습니다."

### 적용 방법 / 절차

1. 자료 조사 시작 전 **수집할 요소 목록** 미리 작성 (템플릿 구조 기준)
2. 각 요소가 채워지면 해당 항목 조사 즉시 종료
3. 수집한 정보는 반드시 내 언어로 재작성

### 주의 사항

- 완벽한 자료를 찾으려다 시간을 낭비하는 것이 왕초보의 가장 흔한 실수
