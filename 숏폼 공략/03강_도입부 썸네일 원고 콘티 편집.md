## TL;DR

- 모든 썸네일·제목·도입부 멘트는 **주제 + 구조** 두 층으로 되어 있다. 구조만 뽑아 나만의 구조 사전에 저장하면 영구 재활용 자산이 된다.
- 구조 분석은 **큰 맥락(의미 덩어리)**과 **잘게 쪼개기(A·B·C 치환)** 두 방법으로 진행하고, A·B에 넣을 단어 의미를 친절하게 적어둬야 6개월 뒤에도 바로 쓸 수 있다.
- 문구 강화 5가지(단어·수치·표현·단순화·타겟 지칭)는 과도하게 조합하면 오히려 신뢰를 깎는다. 단백한 것이 더 잘 될 때도 많다.
- 숏폼 도입부는 **1초 만에 사로잡아야** 한다. 도입부 멘트 + 화면 + 표시 제목 세 요소가 동시에 작동해야 한다.
- 제작 순서: 도입부 → 표시 제목 → 썸네일 → **원고 (300자/30초, 600자/1분)** → 콘티 → **녹음 먼저** → 촬영 → 편집 → 검수·렌더링·업로드.
- 왕초보는 고민보다 제작량이 먼저다. 피드백 루프를 많이 겪는 것이 퀄리티 향상의 유일한 경로.

## 🎯 왜 구조 분석인가 — 주제 vs 구조 개념

> **유형**: 개념
> **타임스탬프**: [15:30] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=930

### 한 줄 요약

같은 주제라도 어떤 구조를 입히느냐에 따라 클릭률과 조회수가 천지차이가 된다.

### 핵심 내용

- 모든 썸네일 문구·제목·도입부 멘트는 **주제**와 **구조** 두 층으로 구성된다.
- 주제는 콘텐츠의 본질, 구조는 본질을 빛나게 하는 포장지.
- 같은 주제 "꿀수박 고르는 법" → 두 가지 표현 비교:
  - 버전 A: `꿀수박 고르는 법`
  - 버전 B: `아는 사람만 골라간다는 꿀수박 고르는 초간단 방법`
  - 버전 B가 끌리는 이유: "아는 사람만 안다"는 표현이 궁금증을 자극하기 때문.

### 강사 비유 / 예시

> "주제가 본질이라면 구조는 본질을 빛나게 하는 포장지 같은 거죠."

### 적용 방법 / 절차

1. 합비디오(VidIQ) 영상의 썸네일 문구·제목에서 주제와 구조를 분리하는 연습.
2. 분리한 구조를 나만의 **구조 사전**에 저장.
3. 내 콘텐츠 주제와 구조를 결합 → 클릭률 높은 문구 완성.
4. 숏폼이라면 인기 영상 도입부 **첫 3초**도 같은 방법으로 구조를 분석해 조합.

### 주의 사항

- 구조만 가져와서 내 주제와 합치면 **벤치마킹**.
- 구조 + 주제 둘 다 그대로 복사하면 **표절·카피 — 절대 금지**.

## 🎯 구조 분석법 ① — 큰 맥락으로 분석하기

> **유형**: 프로세스
> **타임스탬프**: [16:34] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=994

### 한 줄 요약

문장을 의미 덩어리로 나눠 각 덩어리가 시청자에게 어떤 의미로 전달되는지를 파악한 뒤 구조로 명명한다.

### 핵심 내용

**분석 사례: 관광지 썸네일**

| 원문 | 의미 | 구조 명칭 |
|---|---|---|
| "와, 입이 다물어지지 않네." | 주의를 끄는 놀람 | 놀라는 감탄사 |
| "어떻게 지었을까?" | 궁금증을 자극 | 궁금증 유발 질문 |
| "한국인이라면 꼭 가봐야 할 곳" | 가치를 준다는 약속 | 가치 약속 |

**골프 채널 적용 예시 (실제 **30만 조회수** 발생)**

> "와, 입이 다물어지지 않네요. 어떻게 가볍게 치는 걸까? 아이언 **150m** 안 나가면 꼭 봐야 함"

→ 관광지 주제를 아이언 치는 법으로 바꾸고, 구조(감탄사 + 궁금증 + 가치 약속)는 그대로 활용.

### 강사 비유 / 예시

> "이 채널이 원래 조회수가 낮은 채널이었거든요. 근데 주제에 좋은 구조를 조합해서 썸네일을 만들다 보니까 높은 조회수가 발생을 하게 된다는 거죠."

### 적용 방법 / 절차

1. 주제가 무엇인지 먼저 파악.
2. 각 문장·단어가 목표 시청자에게 **어떤 의미로 전달될까?** 자문하며 의미를 적음.
3. 의미를 순서대로 나열 → 큰 맥락에서의 구조 완성.
4. 구조를 따로 저장 → 나중에 내 주제와 결합.

### 주의 사항

- 구조 명칭은 정해진 게 없다. 나한테 착 붙는 말로 바꿔도 됨.
  - 놀라는 감탄사 → "서프라이즈 멘트"
  - 궁금증 유발 질문 → "호기심 제시", "궁금증 제시"
- 미드폼 원고 도입부를 받아쓸 때도 큰 맥락으로 분석해 저장하면 초반 유지율에 긍정적 영향.

## 🎯 구조 분석법 ② — 잘게 쪼개기 (A·B·C 치환)

> **유형**: 프로세스
> **타임스탬프**: [18:30] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=1110

### 한 줄 요약

의미를 전달하는 핵심 단어만 골라 A·B·C로 치환하고, 각 변수에 어떤 의미의 단어를 넣어야 하는지 메모해 둔다.

### 핵심 내용

**분석 사례: 피부 관련 썸네일**

원문: `피부과 의사가 알리지 말라던 피부 좋아지는 비밀 공개합니다`

| 분석 요소 | 내용 |
|---|---|
| 주제 | 피부 좋아지는 법 |
| 큰 맥락 구조 | 권위 있는 사람 + 은폐·숨김 + 같이 폭로하기 |
| A·B 치환 | **A**는 알리지 말라던 **B** 공개합니다 |
| A의 의미 | 타겟이 정보를 캐고 싶은 사람 (권위자) |
| B의 의미 | 타겟이 원하는 해결책 |

**다른 주제에 적용:**
- 살림 꿀템 → `다이소 직원이 절대 안 알려주는 살림 꿀템 3가지 공개합니다`
- 곰팡이 제거법 → `청소대표가 알리지 말라던 묵은 곰팡이 제거법`

### 강사 비유 / 예시

> "너무 좋죠. 그래서 지금 설명드린 게 잘게 쪼개서 구조 분석을 하는 방법입니다."

### 적용 방법 / 절차

1. 주제 파악.
2. 의미를 전달하는 핵심 단어를 A, B, C로 치환. (호기심 증폭 장치 같은 수식어는 핵심 단어가 아님.)
3. A, B 각각에 **어떤 의미의 단어**를 넣어야 하는지 친절하게 적기.
4. 구조 사전에 저장.
5. 나중에 A·B에 내 주제 단어를 대입 → 문구 완성.

### 주의 사항

- A, B에 넣을 의미를 **친절하게** 적어둬야 3~6개월 뒤에도 바로 적용 가능. 대충 적으면 나중에 다시 분석해야 함.
- 변수는 A 하나만, A B C, A B C D 등 자유롭게 구성.
- 큰 맥락 분석이 상대적으로 쉬우므로 **큰 맥락부터 시작** 권장.
- ChatGPT에 구조 분석을 시킬 수 있지만, 강사가 직접 시켜본 결과 제대로 못 하는 경우도 있음 → **내가 먼저 능력을 갖춰야 AI 결과물을 검증 가능**.

## 🎯 구조 사전 구축 & 유지 원칙

> **유형**: 체크리스트
> **타임스탬프**: [20:39] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=1239

### 한 줄 요약

구조는 유통기한이 없으므로 많이 모아둘수록 이득이고, 저장 도구는 편한 것 아무거나 쓰면 된다.

### 핵심 내용

- 구조는 유통기한 없음 — **1년 후에도 그대로 사용 가능**.
- 구조 분석 대상 선정 기준 (합비디오/VidIQ):
  - 유명인·귀여운 동물 콘텐츠 **제외** (조회수가 콘텐츠 가치 때문이 아님).
  - 콘텐츠 가치로 조회수가 나온 영상.
  - **구독자 적은데 조회수 높은 게 베스트**.
- 저장 도구: 워드, 노션, 메모장 — 편한 것 아무 곳이나.
- 다다익선 — 구조가 많을수록 고수처럼 문구를 만들 수 있다.

### 강사 비유 / 예시

> "이거는 많이 모아둘수록 좋다. 다다익선이라고 말씀드리겠습니다."

> "저희 68년생 어머니도 구조 분석 잘 하고 계십니다. 연습만이 살길이다."

### 주의 사항

- 처음엔 내가 한 게 맞는지 의문이 드는 게 정상. 연습하면 요령 생김.
- 합비디오 뷰트랩(뷰 트랩) 분석뿐 아니라 **미드폼 원고 받아쓸 때도 도입부 구조를 분석해 저장** 권장.

## 🎯 제목·문구 강화 5가지 방법

> **유형**: 체크리스트
> **타임스탬프**: [21:01] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=1261

### 한 줄 요약

단어·수치·표현·단순화·타겟 지칭 다섯 가지를 상황에 맞게 조합하되, 다 넣으면 과유불급이다.

### 핵심 내용

| # | 방법 | 설명 | 예시 |
|---|---|---|---|
| 1 | **단어 강화** | 평범한 단어를 강력한 단어로 교체 | `돈 버는 방법` → `돈 버는 치트키` → `부자 되는 비밀 노하우` |
| 2 | **수치 강화** | 모호한 표현을 구체적 숫자로 | `주방 살림 편해지는 꿀팁` → `주방 살림이 **200%** 편해지는 꿀팁 **3가지**` |
| 3 | **표현 강화** | 형용사·실제 사용자 어투로 문장 전체를 강화, 수치 강화와 조합 가능 | `초고속으로 부자 되는 방법` / `억소리 나게 돈 버는 전략` / `미친 듯이 돈 버는 사람들의 비밀` → 수치 추가 시 `초고속으로 **100억** 부자 되는 **30일** 루틴` |
| 4 | **문장 단순화** | 초등학교 3학년도 이해할 수 있는 단어로, 짧을수록 좋음 | 어려운 전문 용어 → 쉬운 대체어 |
| 5 | **타겟 지칭** (칵테일 파티 효과) | 썸네일·표시 제목·도입부에 타겟 지칭 명사 삽입 | `30대 직장인은 꼭 들으세요` / `예비 신부들은 절대 이거 모르면 안 됩니다` / `송파구 사는 사람들은…` |

### 강사 비유 / 예시

> "정말 북적북적한 칵테일 파티에서 여러분께서 혼자 멍하니 서 있는 겁니다. 소음이 너무 심해. 그런데 저기 멀리서 누가 본인의 이름을 부른 겁니다. 그러면 그 소음을 뚫고 내 이름이 탁 귀에 들어오거든요. 이게 칵테일 파티 효과입니다."

### 주의 사항

- 5가지 전부 넣으면 **과유불급** — 문장이 길어지거나 지나치게 비현실적이 되어 신뢰 하락, 클릭률 감소.
- **단백한 게 더 잘 되는 경우도 많다**.
- 타겟 지칭은 특정 타겟에 판매하는 경우 특히 효율적.

## 🎯 도입부의 중요성 — 1초 만에 사로잡아야 한다

> **유형**: 개념
> **타임스탬프**: [23:48] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=1428

### 한 줄 요약

전 세계에서 하루 수백만 개의 숏폼이 만들어지는 환경에서, 정보의 가치가 아무리 좋아도 도입부가 주의를 끌지 못하면 의미 없다.

### 한 줄 요약

초보 레벨은 고민한다고 퀄리티가 오르지 않는다. 제작량을 늘려 피드백 루프를 많이 겪는 것만이 성장 경로다.

### 핵심 내용

- 왕초보의 흔한 실수: 영상 제작 시 고민을 너무 많이 함.
- **초보 레벨은 고민한다고 퀄리티가 오르는 단계가 아니다.**
- 처방: 제작량을 늘려 → 빨리 배우고 → 개선·수정·재적용 → 피드백 루프를 많이 겪기.
- 꾸준히 3개월, 6개월, 9개월 하면 성과가 보인다.
- 숏폼도 미드폼과 마찬가지로 **끈기와 인내**가 핵심.

### 강사 비유 / 예시
