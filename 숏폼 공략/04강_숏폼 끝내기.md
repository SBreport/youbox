## TL;DR

잘된 숏폼을 **분해 → 강점 저장 → 내 영상 적용**하는 루틴. 카피가 아니라 성공 요소를 재해석하는 것이다. 강사가 7개월 만에 60만 팔로워를 달성한 핵심 비법이며, 매일 **2시간** 지속하면 나만의 템플릿·트렌드 감각·고성과 패턴 구사력이 생긴다.

## 🎯 숏폼 끝내기 — 정의와 의의

> **유형**: 개념
> **타임스탬프**: [34:56] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=2096

### 한 줄 요약

내 카테고리(또는 타 카테고리)에서 잘된 숏폼을 분해해 성공 요소를 나의 것으로 재해석하는 반복 루틴.

### 핵심 내용

- **목표**: 잘된 영상 분해 → 각각의 강점 파악 → 내 채널 적용
- **핵심 원칙**: 그대로 카피 X. 성공 요소를 분해한 뒤 **나의 언어·스타일로 재해석**
- **별칭**: "**슈퍼 노멀의 숏폼 버전**"
- **매일 하면 얻는 것**
  - 나만의 숏폼 템플릿 (키 콘텐츠·풀링 콘텐츠 모두)
  - 트렌드 캐치 능력 (숏폼은 소비 속도가 빠름)
  - 고성과 영상 패턴 학습
  - 트래픽 → 수익화 연계 → **매출 증가**

### 강사 비유 / 예시

> "슈퍼 노멀의 숏폼 버전이라고 생각하시면 되겠습니다."

> "이걸 하다가 본인 입맛에 맞게 조금 변형을 하셔도 상관없겠습니다."

### 주의 사항

- 난이도가 쉽지 않다. 하지만 매일 하면 얻는 것이 크다.
- 처음에는 캄캄하게 느껴지는 것이 정상 — 패턴은 **누적** 이후에 보이기 시작한다.

## 🎯 강사의 숏폼 끝내기 자기 사례

> **유형**: 사례
> **타임스탬프**: [45:30] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=2730

### 한 줄 요약

2022년 1월부터 매일 밤 **12시~새벽 2시** **2시간**씩 비공개 블로그에 패턴 분석을 누적 → 천만 조회수 쇼츠 반복 달성.

### 핵심 내용

- 시작 시점: **2022년 1월**
- 시간: 매일 **밤 12시 ~ 새벽 2시**, **2시간**
- 도구 변천: 비공개 블로그 → 워드 파일 → 엑셀 (현재)
- 초기에는 잘된 영상을 틀어두고 아무것도 몰라 그냥 봄 → 비공개 블로그에 패턴 분석 꾸준히 기록
- 결과: 성공 패턴이 점차 눈에 보이기 시작 → 검증·적용 → 평균 조회수 급증 → **천만 조회수 쇼츠** 지속 제작

### 강사 비유 / 예시

> "처음에는 저는 그냥 아무것도 없었어요. 그냥 잘된 영상 보면서 화면을 켜두고 가만히 있었습니다. 아무것도 몰랐어요. 근데 제 비공개 블로그에 빨강으로 그냥 계속 패턴 분석을 했습니다. 그러다 보니까 점차 성공 패턴이 보이기 시작하고."

### 주의 사항

- **어제도 새벽 2시까지 진행**했다고 강조 — 강사 본인이 현재도 진행 중인 루틴.

## 🎯 잘된 숏폼 찾기 — 선정 기준

> **유형**: 체크리스트
> **타임스탬프**: [36:08] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=2168

### 한 줄 요약

한국 기준 좋아요 **5,000개 이상**이 기준. 채널·개인 가치로 잘된 영상은 제외하고 콘텐츠 가치만 본다.

### 핵심 내용

- **기본 기준**: 좋아요 **5,000개** 이상
- **소규모 카테고리**: 좋아요 **1,000개** 이상도 충분
- **반드시 제외**: 채널 가치(구독자 영향) / 개인 가치(얼굴·명성) 때문에 잘된 영상
- **선정 조건**: 순수 **콘텐츠 가치**로 잘된 영상만

### 주의 사항

- 채널이 크거나 크리에이터가 유명해서 잘된 영상은 구조 학습 가치가 낮음.
- 열 개만 분석해도 "어떤 성공 패턴을 내 영상에 적용해야 하는지 바로 확 느껴진다"고 강조.

## 🎯 잘된 숏폼 찾기 — 4가지 소스

> **유형**: 체크리스트
> **타임스탬프**: [36:44] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=2204

### 한 줄 요약

뷰트랩 / 합비디오(VidIQ) / 인스타(모바일 필수) / 틱톡 네 곳을 루틴으로 순회한다.

### 핵심 내용

#### ① 뷰트랩
- 내 카테고리 키워드 검색 → 쇼츠 만보기
- 콘텐츠 가치 영상만 선정

#### ② 합비디오 (VidIQ 추정)
- 쇼츠 만보기 → 비정보성 제외, 정보성만
- 최신 외에 과거 **8월 / 7월 / 6월**로 거슬러 올라가며 탐색

#### ③ 인스타 (모바일 필수)
- 내 카테고리 키워드 검색 → 릴스 탭 진입
- 조회수 바로 확인 가능 → 고성과 영상 선정
- 저장 또는 좋아요로 북마크

#### ④ 틱톡
- 키워드 검색 → 동영상 탭 → 좋아요 수 확인 → 즐겨찾기 저장
- 추천 탭: 좋아요 **5,000개+** / **1만 개+** 정보성 영상 저장
- **티어드 인기 검색어**: 트렌드 영감 수집 → 단, 바로 제작 X → **반드시 뷰트랩으로 검증** 후 진행

### 강사 비유 / 예시

> "이 영감을 받았지만 바로 제작을 하시면 안 되고 뷰트랩으로 검증을 해 주시는 걸 추천드리도록 하겠습니다."

### 주의 사항

- 틱톡 인기 검색어는 영감 수집 용도. 주제 선정 도구가 아니라 성공 요소 분석 도구임을 혼동 금지.
- 인스타는 PC 릴스 배속 조절을 위해 모바일과 병행 사용.

## 🎯 분석 항목 ② — 원고 받아쓰기

> **타임스탬프**: [38:51] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=2331

### 한 줄 요약

배속 **0.25~0.5배**로 받아쓰기. 크롬 확장 **유튜브 플레이 스피드 컨트롤** 사용. 슬래시(/)로 텍스트 단락 구분.

### 핵심 내용

- **추천 크롬 확장**: `유튜브 플레이 스피드 컨트롤`
  - 설치 후 **0.25 / 0.5 / 2배속** 조절 가능
  - 인스타 릴스를 PC에서 볼 때: 링크 새 탭으로 열기 → **0.25 / 0.5배속** 표시 나타남
  - 속도 표시 안 보이면: **두세 번 새 탭**으로 다시 열기
- **슬래시(/) 구분**: 텍스트 속도 및 글자 수 확인용 (선택 사항)

### 강사 비유 / 예시 — 패션 릴스 받아쓰기 샘플

> "주우제 패션만 보고 따라해줘도 무조건 보통 이상은 할 수 있어요. / 주우제 패션으로 보는 2024년 남자 여름 코디 / 첫 번째 코디 — 검은색 나일론 재킷 더불어 회색 반팔티 위에 기능성 조끼 그리고 흰색 바지와 검은색 신발"

### 주의 사항

- 숏폼은 말이 빠르므로 일반 배속으로 받아쓰면 누락 다수 발생.
- 원고 완성 후 → **도입부 / 본문 / 결론 분리** 작업으로 넘어갈 것.

### 핵심 내용

| 구간 | 분석 포인트 |
|------|------------|
| **도입부** | 멘트 구조 분석 (`A=`, `B=` 변수화) → 도입부 구조 사전 누적 |
| **본문** | 어떤 템플릿형인지 (나열형·순서형·스토리형·주장 설득형 또는 신규 파악) → 패턴화 |
| **결론** | 행동 버튼 유무 → 없으면 아쉬운 점으로 메모 |

- **본문 개선 메모**: 강사 사례 — 패션 영상에 혜택 없음·연관 제품 추천 없음 → 파란색으로 추가 메모

### 강사 비유 / 예시

> "숏폼 끝내기를 지속하다 보면 이것도 내가 도입부는 결론도 잘 발라내실 겁니다. 패턴이 눈에 보이실 거거든요."

> "이 영상은 행동 버튼이 없다라는 게 아쉽다. 그걸 또 적어 두면 좋겠습니다."

### 주의 사항

- 숏폼 끝내기를 반복할수록 분리 능력이 자동 향상됨. 처음에 잘 못 나눠도 괜찮다.
- 도입부 멘트 재사용 시: **단어 강화 / 표현 강화 / 수치 강화**로 반드시 재해석할 것.

## 🎯 분석 항목 ④ — 화면·사운드·영상 템포

> **유형**: 체크리스트
> **타임스탬프**: [42:04] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=2524

### 한 줄 요약

초반 화면 구성 / 본문 집중도 유지 방식 / 화면 전환 속도 / 자막·BGM·음성·효과음 / 전체 템포를 항목별로 기록한다.

### 핵심 내용

#### 초반 화면
- 어떤 구성인지, 속도는 어떤지 → 시선을 잡았는가?
- 강사 사례: 패션 영상 초반 템포를 빠르게 해서 패션을 소개하며 시선을 잡음

#### 본문 화면
- 정보 이해 용이성 + 집중도 유지 관점으로 분석
- 항목: 확대/축소, 화면 포인트 표시, 시각 효과, 본인 등장 시 아이컨택

#### 화면 전환 속도
- **0.5초 / 1초 / 2초** 실측
- 내 카테고리와 비슷한 채널이라면 그 속도에 맞춰야 함

#### 자막·BGM·음성·효과음

| 항목 | 분석 포인트 |
|------|------------|
| 자막 | 스타일·폰트 |
| BGM | 영상 분위기·감정 형성 방식 |
| 음성 | 개성 유무, 발음, 말하는 방식 |
| 효과음 | 이해·집중도 목적에 맞는지. 남발 X — 제작 시간 증가 주의 |

#### 전체 템포
- 내 카테고리가 빠른 편이라면 나도 빠르게 맞춰야 함

### 강사 비유 / 예시

> "효과음을 너무 많이 쓰려고 하면 제작 시간이 많이 걸린다는 점 꼭 기억해 주셔야 되겠습니다."

### 주의 사항

- 효과음 기준: **목적 없는 남발 X**, 집중도 유지에 직접 기여하는 것만.
- 화면 전환 속도는 타 카테고리 영상이면 참고만. 내 카테고리 영상일 때만 동기화 필요.

> **타임스탬프**: [43:35] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=2615

### 한 줄 요약

영상 전체에서 감정이 발생하는 지점을 세어라. 잘된 숏폼은 **10초당 1개**, 100만·천만 뷰 영상은 **5~6초당 1개**.

### 핵심 내용

- **감정 유형**: 웃음 / 감탄 / 슬픔 / 흥미 등
- **확인 방법**: 내 주관 기록 + 댓글에서 시청자 반응 지점 추출
- **잘된 숏폼 비밀**

| 등급 | 감정 포인트 밀도 |
|------|-----------------|
| 잘된 숏폼 기본 | **10초당 1개** |
| 100만·천만 뷰 영상 | **5~6초당 1개** |

- 이 밀도를 맞추면 흥미·집중도·완시청률이 함께 올라감.
- 반복 분석 → 내 감과 시청자 감이 점점 일치하게 됨.

### 강사 비유 / 예시

> "5초마다 와 웃기다, 오 대박이다 이런 식으로 돼야 된다는 거죠."

> "잘된 숏폼 영상은 적어도 10초에 한 개씩은 감정을 느끼는 포인트들이 배치가 되어 있습니다."

### 주의 사항

- 크리에이터가 의도했는지 여부와 무관하게, 잘된 영상에는 이 패턴이 공통으로 나타남.
- 감정 포인트 밀도는 **영상 기획 단계**부터 의식적으로 설계해야 달성 가능.

## 🎯 숏폼 끝내기 — 한계와 효용

> **유형**: FAQ
> **타임스탬프**: [45:30] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=2730

### 한 줄 요약

처음엔 한 편당 **1시간** 소요. 꾸준히 하면 양산형과 차이가 벌어지고, 수십만~수백만 조회수가 **보장적**으로 나오는 능력이 생긴다.

### 핵심 내용

- **초기 소요 시간**: 한 편당 약 **1시간**
- 꾸준히 누적하면 → 성공 요인이 내 것이 됨 → 고성과 숏폼 반복 제작 능력 획득
- **양산형 숏폼** (조금 나오는 데 만족) vs **고성과 숏폼** (몇십만~몇백만 보장적 조회수)
- 강사 크리에이터 시절 루틴: 매일 **숏폼 끝내기 2시간** + 영상 제작 **12시간**

### 강사 비유 / 예시

> "양산형으로 숏폼 그냥 막 만들어 가지고 조회수 조금 나오는 데 만족하는 것과 제대로 만들어지게 되면서 몇백만 몇십만이 보장적으로 나오는 그러한 숏폼을 만드는 능력. 어떤 걸 하고 싶겠습니까?"

### 주의 사항

- "보장적"은 패턴을 내 것으로 만든 이후의 기대값. 초반 누적 없이는 달성 불가.
