## 🧩 프레임워크·공식

### 육아 카테고리 회원 사례 — 출발점이 어디든 가능하다

5강에서 키 숏폼 전략을 배웠다면, 6강의 출발은 실제로 일어난 결과로 시작한다.

뷰트랩 → 쿠팡 파트너스로 시작한 육아 카테고리 회원. 기존에는 유튜브 미드폼으로 공동구매 매출을 내던 크리에이터였다. 17주차 숏폼 강의 수강 후 인스타 릴스를 시작, 2개월 만에 팔로워 2만을 달성했다. DM으로 공동구매 문의가 쏟아지는 상태이며, 자체 KC 인증 육아용품 출시를 앞두고 있다. 강사: "이분도 뷰트랩에서 쿠팡 파트너스로 시작하셔 가지고 저기까지 도달하신 거죠."

이 사례의 메시지는 하나다. 출발이 작아도 방향이 맞으면 도달한다.

### 숙련도 곡선과 시간 활용 전략

숙련도 곡선은 반드시 기억해야 할 원리다. 첫 영상에 노력 100이 들어가지만 B, C, D로 갈수록 줄어든다. 문제는 남는 시간을 어디에 쓰는가다.

| 상황 | 선택지 |
|------|--------|
| 미드폼 주력 | 미드폼 추가 제작 OR 숏폼으로 원소스 멀티유즈 |
| 숏폼 주력 | 주 최소 3개 제작 |
| 강점을 모르겠다 | 내 카테고리 1~10등 채널 벤치마킹 |

**이 표의 의미**: 선택지는 세 가지지만 공통 원칙은 하나다. 남는 시간에 성장 활동을 넣어야 한다. 강사: "남는 시간에 놀아버리면서 성장 정체된 크리에이터들을 제가 정말 많이 봤거든요." 강점이 미드폼인지 숏폼인지 모른다면, 카테고리 상위 채널이 어떻게 운영하는지 먼저 벤치마킹한다.

**인과 사슬**:
```
숙련도 상승 → 영상 1편 제작 시간 단축
  → 남는 시간 발생
  → A: 숏폼 추가 제작 → 피드백 빈도 ↑ → 실력 상승 가속
  → B: 놀기 → 성장 정체
∴ 남는 시간 활용이 채널 성장 속도의 갈림길
```

### 이번 주 실행 계획 — 미션 2가지

이번 주 목표는 분석 + 제작 두 트랙을 동시에 시작하는 것이다.

**미션 1. 숏폼 끝내기 3개**
- [ ] 내 카테고리 또는 정보성이면서 다른 카테고리 영상 선택
- [ ] 도입부 멘트·표시 제목 구조 분석
- [ ] 초반 3초가 어떻게 나를 멈추게 했는지 분석

**미션 2. 숏폼 제작 최소 1개**
- [ ] 주제 3개 선정 (아래 5소스 + 뷰트랩 검증)
- [ ] 그 중 최소 1개 실제 제작 (풀링 숏폼 / 키 숏폼 모두 OK)

강사: "처음 만드는 대부분의 쇼츠는 조회수가 1만도 아마 안 나오실 거예요. 저도 2주 동안 처음 할 때 숏폼이 조회수가 0이었거든요. 걱정 마세요. 다 성장을 하더라고요."

> [!NOTE]
> **카피 절대 금지** — 구조 분석은 OK, 영상 내용을 그대로 베끼는 것은 불가. 핵심은 "숏폼을 잘 만드는 과정을 한 번 밟아보자"다.

### 주제 선정 추가 5소스

뷰트랩 외에 어디서 주제를 발굴하는가?

| 채널 | 방법 |
|------|------|
| **인스타 (모바일 필수)** | 키워드 검색 → 릴스 탭 → 조회수 높은 순 → 뷰트랩 재검증 |
| **틱톡 (모바일/PC)** | 키워드 검색 → 인기/동영상 탭 → 좋아요·조회수 높은 순 |
| **틱톡 인기 검색어** | 인기 검색어에서 영감 → 뷰트랩 검증 후 제작 |
| **네이버 지식인** | 주제 키워드 검색 → 자주 묻는 질문에서 소재 발굴 |
| **타겟 커뮤니티** | 타겟이 모이는 카페·포럼의 인기 글에서 소재 선정 |

**이 표의 의미**: 소스마다 성격이 다르다. 인스타·틱톡은 이미 숏폼에서 성과가 검증된 주제, 지식인·커뮤니티는 타겟이 실제로 궁금해하는 질문이다. 두 유형을 교차 활용하면 성과 검증 + 수요 확인이 동시에 된다.

**강사 예시**: 요식업 컨설팅이라면 뷰트랩과 아프리카 사장이다 카페. 남자 패션이라면 뷰트랩과 한국 커뮤니티, 외국 인스타·틱톡. 핵심 원칙은 "내 타겟 시청자들의 행동 반경이 어디인지 이해하고, 거기서 주의가 끌리는 것을 찾아내는 것이다."

**최종 검증은 반드시 뷰트랩**: 어느 소스에서 발굴하든 최종 주제 확정 전 뷰트랩으로 검증하는 단계가 필수다.

### 카테고리별 조회수 마지노선 찾는 법

주제를 선정할 때 어느 조회수 이상의 영상만 참고해야 할까? 카테고리마다 다르므로 강사가 일률적 수치를 줄 수 없다. 직접 데이터를 쌓아야 한다.

```
1. 리스트 조회수 높은 순으로 1위부터 주제 선정 → 영상 제작
2. 내 채널에서 조회수 실제 확인
3. "이 주제는 좋았다 / 별로였다" 감이 생기면
4. 별로인 주제의 조회수 수치 = 내 채널 마지노선
5. 그 이상인 숏폼만 이후 주제로 선정
```

강사 예시: 코미디는 조회수 100만 이상이어야 참고할 만하고, 살림은 10만 이상이어야 할 만하다는 식으로 나만의 기준이 생긴다. 이것은 가르쳐줄 수 있는 지식이 아니라 직접 경험해서 체득하는 영역이다.

### 33만 릴스 워크스루 — "A에서 난리난 B" 구조

실제 33만 조회수를 기록한 육아 릴스를 처음부터 끝까지 트레이싱한다.

**원본 영상 분석**

| 구성 요소 | 내용 |
|-----------|------|
| **주제 발굴** | 해외 숏폼에서 발굴한 양쪽 두뇌 발달 놀이 (국내 미소개 주제) |
| **도입부 멘트 구조** | "A에서 난리난 B" → A=달성 영역(해외), B=결과·노하우 |
| **표시 제목** | 없음 (있으면 더 좋음 — 파란색 메모로 개선점 기록) |
| **후킹 화면** | 영상 시작부터 종이를 흔드는 행동 장면 → 시각적 후킹 |
| **본문** | 양손을 동일하게 쓰면 양쪽 두뇌 발달에 좋다는 혜택 설명 |
| **결론** | 팔로워 요청 행동 버튼 |

**이 표의 의미**: 분석의 핵심은 도입부 멘트 구조다. "A에서 난리난 B" 구조는 A와 B에 다른 값을 넣어 무한 응용할 수 있다.

응용 예시:
> "해외에서 난리난 두뇌 발달 놀이"
> "대전에서 난리난 성심당 신상빵"
> "코스피에서 현재 난리난 국내 주식"

**제작 순서**:
```
주제 선정 → 원고 작성 → 콘티 구성 → 녹음 (또는 촬영 먼저) → 편집 → 업로드
```

유튜브·인스타·틱톡 동시 업로드 (가능하면 쓰레드도 추가).

**콘티 작성법**: 처음에는 짧게 "놀이하는 모습 / 박자 맞춰서" 수준만 적어도 충분하다. 더 나아가면 문장마다 장면을 글로 기록한다 (예: "다이소 전경 블러 처리 / 주방 배경으로 키친타월 툭 뽑는 장면"). 핵심은 촬영 전에 장면 구성을 끝내고 들어가는 것이다.

강사: "단백하게 시작해서도 후킹이 가능하기 때문에, 초반 도입부 후킹 장면이 뭔가를 흔들거나 역기적인 장면이어야만 사람들이 멈추는 게 아닙니다."

### 숏폼 끝내기 간소화 4가지 — 편당 10~20분

4강에서 배운 9가지 항목 전체를 매번 채우기 어렵다면, 이 4가지 핵심만 채워도 충분하다.

| # | 항목 | 설명 |
|---|------|------|
| 1 | **도입부 멘트·표시 제목 구조 분석** | 표시 제목 없으면 생략. 구조를 언어화해 두기 |
| 2 | **내 마음을 어떻게 홀렸나** | 멘트·화면·사운드 통합해서 이유 적기 |
| 3 | **원고 전개 템플릿 파악** | 도입 → 주장 → 설명 → 교훈 흐름 도식화 |
| 4 | **전체에서 내 마음이 가장 홀린 부분** | 어느 순간에 가치를 느꼈는지 핀포인트 |

**이 표의 의미**: 4가지는 전부 "내가 왜 멈췄는가"에 대한 질문이다. 시청자도 나와 같은 감각을 가진 사람이다. 내가 멈춘 이유가 시청자가 멈추는 이유다. 이것을 언어화하고 쌓으면 무의식적 성공 패턴 학습이 된다.

**권장 빈도**:

| 수준 | 빈도 |
|------|------|
| 최소 | 주 3개 |
| 권장 | 하루 1개 |
| 강사 기준 | 하루 5개 |

이걸 쌓으면 생기는 것: 나만의 구조 라이브러리, 무의식적 성공 패턴 학습, 좋은 주제를 보는 눈, 현재 트렌드 감지 능력.

강사: "제가 3개월 동안 60만 팔로워를 찍었던 비결 중 하나가 이거거든요. 성공한 크리에이터들 중에서 잘된 영상 분석 없이 성공한 사람이 없습니다."

### 주피디 370만 쇼츠 — "히어로 교훈 형식" 해체

간소화 4가지를 실제로 어떻게 적용하는지 370만 조회수 영상으로 실전 시연한다.

**원본 영상 개요**:
"한 달에 1억 넘게 벌고 있는 친구가 저한테 알려준 내용인데요. 목표를 크게 가지라는 말에 진짜 의미가 있다는 거예요."

분필 1명 → 와이프 / 10명 → 친구 / 100명부터 갈림 / 만 명 → 스마트스토어 / 천만 명 → 아마존. "목표의 크기가 내 방법을 정한다." 의도적 자기 낮춤: "근데 팀은 안 했어요. 어리니까."

**항목 1. 도입부 멘트·표시 제목 구조 분석**

도입부 구조: `A가 달성한 B가 저한테 알려준 내용인데요`

| 변수 | 속성 |
|------|------|
| **A** | 타겟이 원하는 목표 수치 (예: 한 달에 1억) |
| **B** | 사람을 지칭하는 말 (예: 친구, 선생님, 아버지) |

이 구조를 다이어트 채널에 응용하면: "운동 없이 30kg 뺀 해외 유튜버가 자신의 유료 고객들한테만 공유한 비법인데요."

**항목 2. 내 마음을 어떻게 홀렸나**

"내가 원하는 상황을 살고 있는 히어로가 조언했다고 하니까 궁금해져서 멈췄다."

**항목 3. 원고 전개 템플릿 — "히어로 교훈 형식"**

```
[도입]
궁금증 유발 + 긍정적 이득 ("오, 그게 뭔데? 나도 돈 벌고 싶은데")

[주장]
핵심 메시지 제시 ("목표를 크게 가져라")

[설명]
빌드업식 근거 전개
1명 → 10명 → 100명 → 만 명 → 천만 명

[통찰력 있는 교훈]
핵심 문구 ("목표의 크기가 내 방법을 정한다")

[의도적 자기 낮춤]
웃음 유발 ("근데 팀은 안 했어요. 어리니까")
```

**항목 4. 전체에서 내 마음이 가장 홀린 부분**

"천만 명을 목표로 하는 순간 아마존을 배우게 된다."

강사 인사이트: "정보를 빌드업으로 풀다가 마지막에 통찰력 있는 문구를 넣으면 이 숏폼의 가치를 확 느끼게 된다." 빌드업 후 찾아오는 깨달음의 쾌감이 공유·저장을 폭발시키고, 그것이 370만 조회수로 이어진다.

## ⚠️ FAQ 10가지 — 실무 쟁점 카드

**Q1: 매주 제작은 어떻게 하나요?**

A. 미드폼 주력이라면 숏폼 주 1개를 별도 제작한다. 숏폼 주력이라면 주 최소 3개 제작이 기본이다.
- 미드폼에서 편집해서 만드는 것이 아니라 순수하게 별개로 제작하는 숏폼 1개
- 미드폼이 너무 벅차면 숏폼은 천천히 해도 됨

---

**Q2: 왜 풀링 10개에 키 1개인가요?**

A. 초보의 안전값이다. 여러 채널 데이터를 평균 낸 검증된 비율이다.
- 매출·전환율이 검증되면 풀링 3:키 1까지 줄여도 OK
- 풀링 숏폼을 많이 올려야 체급이 커지고, 초보는 공동구매·외주 광고에 이점
- 키 숏폼만 올리는 채널은 성장이 더디고 원고 품질이 부족하면 매출 내기 어려움

---

**Q3: 숏폼 vs 미드폼 — 내 상품 판매에 뭐가 낫나요?**

A. 관여도로 결정한다.

| 상품 유형 | 특징 | 숏폼 전략 |
|-----------|------|-----------|
| **저관여** (휴지·소모품 등) | 고민 없이 충동 구매 | 도입 후킹 → 충동 구매 욕구↑ → 행동 버튼으로 직접 판매 |
| **고관여** (자동차·교육·서비스 등) | 검색·고민·심사숙고 후 구매 | 숏폼 → 미드폼 키 콘텐츠 연결 OR 무료 상품 → DB 수집 → 점진 설득 |

강사: "결국 스스로 내 상품에 최적화된 퍼널이 무엇인지 직접 테스트해 보면서 찾는 것이 제일 중요합니다."

> [!TIP]
> 저관여와 고관여의 기준은 상품 종류가 아니라 타겟 고객이 구매 전 얼마나 오래 고민하는지로 판단한다.

---

**Q4: 숏폼 편집은 뭘로 하나요?**

A. 초보에게는 캡컷을 추천한다. 필모라·브루도 OK. 무료 편집 툴이면 무엇이든 가능하다.
- 편집 툴보다 콘텐츠 내용이 먼저
- 익숙한 것 하나 선택해서 깊이 파는 게 여러 툴을 얕게 쓰는 것보다 낫다

---

**Q5: 영상 길이는 어느 정도가 적당한가요?**

A. 알고리즘보다 사람의 마음이 기준이다. 끝까지 보게 만들면 길이는 관계없다.
- 짧아도 두세 번 반복하게 만들면 OK
- 1~2분짜리 쇼츠도 끝까지 보게 만들면 OK
- 플랫폼은 결국 사람이 오래 머무르게 하는 영상을 추천 피드에 올린다

강사: "알고리즘은 늘 바뀝니다. 근데 변하지 않는 것에 집중해야 돼요. 뭐냐? 사람의 마음입니다."

---

**Q6: 미드폼·롱폼 편집해서 숏폼으로 만들어도 되나요?**

A. OK. 단, 초반 3초 후킹에 집중해야 한다.
- 미드폼·롱폼의 후킹 요소를 끄집어내 도입부로 재구성
- 나머지 내용은 그대로 활용해도 무방

---

**Q7: 초반 이탈이 많고 멈추지 않습니다**

A. 전적으로 후킹 문제다. 숏폼 끝내기를 더 많이 하고 도입부 구조를 수집한 뒤 내 영상에 적용하는 것이 유일한 해결책이다.
- 미드폼·롱폼 출신은 도입부를 길고 장황하게 말하는 함정에 빠지기 쉬움
- 숏폼 도입은 한 문장으로 끊는 형식이 효과적
  - "문제들입니다"
  - "앞으로 1년 안에 설거지는 이 방식으로 싹 다 바뀔 겁니다"

강사: "후킹 초반 이탈율은 숏폼 끝내기가 정답이다."

> [!TIP]
> 도입부 멘트를 한 문장으로 끊는 연습부터 시작한다. 숏폼 끝내기에서 수집한 도입부 구조 사전을 제작 전 5분 훑는 것만으로 멘트 속도가 확 빨라진다.

---

**Q8: 롱폼 만드는 데 바빠서 숏폼 할 시간이 없어요**

A. 롱폼 편집본을 숏폼으로 일단 활용한다. 진짜 힘들면 숏폼은 나중에 해도 된다.
- 롱폼이 전환·실질 면에서 보편적으로 더 좋은 경우가 있음
- 롱폼이 안정화되면 그때 숏폼 추가를 권장

---

**Q9: 플랫폼마다 조회수 차이가 나요**

A. 플랫폼마다 시청자와 알고리즘이 다르기 때문에 차이가 난다. 일단 3개 플랫폼 모두에 업로드한 뒤 3곳에서 동시에 터지는 숏폼이 나오면 그 방향으로 집중한다.
- 한 플랫폼만 터지는 게 아니라 3곳 다 터지는 숏폼을 목표로
- 그 숏폼의 이유를 분석해서 지속 적용

---

**Q10: AI로 원고 써도 되나요?**

A. 활용 가능하다. 단, 직접 원고 쓰기 + 숏폼 끝내기로 좋은 원고를 보는 눈을 먼저 길러야 한다.
- 그 능력 없이 AI 결과물을 그대로 쓰면 잘 안 됨
- AI에게 첨삭을 요청하더라도 좋은 질문을 던지려면 내가 원고를 판단하는 능력이 선행돼야 함

강사: "왕초보 때 길러야 하는 건 본인이 직접 원고를 쓰고 숏폼 끝내기도 하면서 좋은 원고가 뭔지 아닌지를 보는 눈을 기르는 겁니다."

> [!TIP]
> AI는 보조 도구다. 원고 초안을 AI로 뽑고 숏폼 끝내기에서 배운 기준으로 직접 첨삭하는 방식이 가장 효과적이다.

## ⚠️ 흔한 실수

**실수 1 — 조회수 0이 나오면 포기**

❌ "첫 영상 조회수 0 → 숏폼이 나한테 안 맞는다" → 조기 철수
✅ 조회수 0은 정상. 강사도 처음 2주는 0이었다. 끝내기 루틴을 지속하면서 숏폼 끝내기 분석과 제작을 동시에 반복

→ 왜 차이가 나는가: 알고리즘이 신규 채널을 인식하는 데 시간이 걸린다. 조기 철수가 가장 흔한 실패 패턴이다. 피드백 루프가 돌아가기 시작하면 갑작스럽게 조회수가 올라오는 것이 일반적이다.

**실수 2 — 분석 없이 제작만 반복**

❌ 숏폼 끝내기 0회 + 영상 제작만 반복 → 성장 속도 정체
✅ 숏폼 끝내기 주 3회 이상 + 영상 제작 병행 → 제작할 때마다 분석 결과 반영

→ 왜 차이가 나는가: 제작만 반복하면 같은 실수를 반복한다. 분석이 있어야 다음 편에서 무엇을 바꿔야 하는지 방향이 생긴다.
