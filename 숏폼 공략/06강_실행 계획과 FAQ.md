### 주제 발굴 채널별 방법

| 채널 | 방법 |
|------|------|
| **인스타 (모바일 필수)** | 키워드 검색 → 릴스 탭 → 조회수 높은 순 → 뷰트랩 재검증 |
| **틱톡 (모바일/PC)** | 키워드 검색 → 인기/동영상 탭 → 좋아요·조회수 높은 순 |
| **틱톡 영광 검색어** | 인기 검색어에서 영감 → 뷰트랩 검증 |
| **네이버 지식인** | 주제 키워드 검색 → 자주 묻는 질문에서 소재 발굴 |
| **타겟 커뮤니티** | 타겟이 모이는 카페·포럼의 인기 글에서 소재 선정 |

### 강사 예시
> "제가 요식업 컨설팅을 한다면 제일 많이 참고할 곳은 뷰트랩과 아프니카 사장이다 카페일 겁니다. 남자 패션을 한다면 뷰트랩과 한국 커뮤니티, 그리고 인스타·틱톡 외국 위주로 아마 봤을 것 같아요."

## 🎯 카테고리별 조회수 마지노선 찾는 법

> **유형**: 프로세스
> **타임스탬프**: [62:26] → https://www.youtube.com/watch?v=wBSFA96sXWw&t=3746

### 한 줄 요약
기준은 내가 직접 데이터를 쌓아서 찾는 것 — 조회수 높은 순 1등부터 전부 만들어 본 뒤 내 채널 결과로 마지노선을 역산한다.

### 프로세스

```
1. 리스트 조회수 높은 것 1등부터 주제 선정 → 영상 다 제작
2. 내 채널에서 조회수 실제 확인
3. "이 주제는 좋았다 / 별로였다" 감이 생기면
4. 별로인 주제의 조회수 수치 = 나만의 마지노선
5. 그 이상인 릴스·쇼츠만 이후 주제로 선정
```

### 강사 예시
> "코미디는 조회수 **100만** 이상이어야 좋네, 살림은 조회수 **10만** 이상이어야 할 만하네. 이렇게 나만의 기준이 생기실 겁니다."

### 주의 사항
- 카테고리마다 기준이 다르므로 강사가 일률적 수치를 줄 수 없음
- 직접 실험해서 체득하는 수밖에 없는 영역

### 영상 분석

| 구성 요소 | 내용 |
|-----------|------|
| **주제 발굴** | 해외 숏폼에서 발굴한 양쪽 두뇌 발달 놀이 (국내 미소개) |
| **도입부 멘트 구조** | "A에서 난리난 B" → **A** = 달성 영역(해외), **B** = 결과·노하우 |
| **표시 제목** | 없음 (있으면 좋음 — 파란색 메모로 남겨둘 것) |
| **후킹 화면** | 영상 시작부터 종이를 흔드는 행동 장면 → 시각적 후킹 |
| **본문** | 양손을 동일하게 쓰면 양쪽 두뇌 발달에 좋다는 혜택 설명 |
| **결론** | 팔로워 요청 행동 버튼 |
| **콘티** | "놀이하는 모습 / 박자 맞춰서 엄마 한 번 아빠 한 번" |

### "A에서 난리난 B" 구조 응용 예시
> "해외에서 난리난 두뇌 발달 놀이"
> "대전에서 난리난 성심당 신상빵"
> "코스피에서 현재 난리난 국내 주식"

### 콘티 작성법
- 처음에는 짧게 "놀이하는 모습 / 박자 맞춰서" 수준만 적어도 OK
- 더 나아가면: 문장마다 장면을 글로 기록
  - 예: "다이소 전경 블러 처리 / 주방 배경으로 키친타월 툭 뽑는 장면"
- **핵심**: 촬영 전에 장면 구성을 끝내고 들어가는 것

### 강사 인용
> "단백하게 시작해서도 후킹이 가능하기 때문에, 초반 도입부 후킹 장면이 뭔가를 흔들거나 역기적인 장면이어야만 사람들이 멈추는 게 아닙니다."

### 제작 순서

```
주제 선정 → 원고 작성 → 콘티 구성 → 녹음 (또는 카테고리에 따라 촬영 먼저) → 편집 → 업로드
```

- 유튜브 · 인스타 · 틱톡 동시 업로드 (가능하면 쓰레드도 추가)

>

### 항목 1. 도입부 멘트·표시 제목 구조 분석

**도입부 구조**: `A가 달성한 B가 저한테 알려준 내용인데요`

| 변수 | 속성 |
|------|------|
| **A** | 타겟이 원하는 목표 수치 (예: 한 달에 1억) |
| **B** | 사람을 지칭하는 말 (예: 친구, 선생님, 아버지) |

**표시 제목 구조**: `A가 달성한 B가 나에게 했던 말` (A, B 속성 동일)

### 항목 3. 원고 전개 템플릿 — "히어로 교훈 형식"

```
[도입]
궁금증 유발 + 긍정적 이득 ("오, 그게 뭔데? 나도 돈 벌고 싶은데")

[주장]
핵심 메시지 제시 ("목표를 크게 가져라")

[설명]
빌드업식 근거 전개
1명 → 10명 → 100명 → 만 명 → 천만 명

[통찰력 있는 교훈]
핵심 문구 ("목표의 크기가 내 방법을 정한다")

[의도적 자기 낮춤]
웃음 유발 ("근데 팀은 안 했어요. 어리니까")
```

> "와, 일론 머스크가 트위터에 공개한 혁신 아이디어 비법 — 진짜 혁신적인 아이디어는 고객의 문제를 해결하는 게 아니라 문제 자체에 의문을 품어야 한다는 거예요."

### 강사 부연
> "결국 스스로 내 상품에 최적화된 퍼널이 무엇인지 직접 테스트해 보면서 찾는 것이 제일 중요합니다. 나에게 맞는 퍼널을 찾는 것, 그게 재밌거든요."

## ❓ Q10. AI로 원고 써도 되나요?

### A. 답변 핵심

### 강사 부연

- AI에게 첨삭을 요청하더라도, 좋은 질문을 던지려면 그 능력이 선행돼야 함

### 강사 인용
> "왕초보 때 길러야 하는 건 본인이 직접 원고를 쓰고 숏폼 끝내기도 하면서 좋은 원고가 뭔지 아닌지를 보는 눈을 기르는 겁니다."
